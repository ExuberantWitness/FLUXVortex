## 3. 独立观测量与 oracle

现有轨迹只记录载荷范数和总体变形范数，不能证明周期波形重复。本次先把以下带符号量纳入每步密封记录及哈希链：

- 当前运行点速度；
- 世界坐标总气动力 `(Fx, Fy, Fz)`，在本工况中分别对应近似弦向、展向、厚度向；
- 参考构形最大展向截面上 4 个 Q16 节点的质心位移 `(ux, uy, uz)`。

逐周期相对误差使用完整 16 相位的向量波形 L2：

`e(a,b) = ||wave_b - wave_a||_2 / max(||wave_a||_2, ||wave_b||_2, eps)`。

冻结验收门：

1. 输入波形跨周期最大绝对差 `<= 1e-13 m/s`；
2. 48/48 步提交，结构/气动 generation、wake convection 均逐步加一；
3. 所有步保持 mandatory separated LEV、joint TEV、free wake 与 CUDA float64；
4. 最大耦合残差 `<=2e-7`、最大结构残差 `<=3e-7`、最大相对功闭合误差 `<=1e-6`；
5. 第 3 周期相对第 2 周期：总力波形 L2 `<=0.10`，翼尖质心位移波形 L2 `<=0.05`；
6. 第 3/2 周期误差不大于第 2/1 周期误差（允许 `1e-12` 数值裕量）。

第 1--4 项定义“多周期积分通过”，第 5--6 项另行定义“观测周期稳态通过”。不得把前者改称后者。

## 4. 执行顺序

1. 扩展轨迹密封记录、独立验证器及篡改回归测试。
2. 建立周期工况与周期波形分析器，先做不求解的时间坐标/输入重复性测试。
3. 运行 16 步单周期 pilot；参数不变，仅诊断容量、残差与运行时间。
4. 从零运行冻结的 48 步三周期主门；不以 pilot 尾迹拼接主结果。
5. 运行受影响的 Q16/LEV/TEV/FSI 回归并生成证据清单。

## 5. 停止与回退条件

- NaN/Inf、CUDA 设备丢失、LEV/TEV/free-wake 模式漂移、粒子容量耗尽或失败步污染已提交 owner：立即停止并修根因。
- 若某步仅因迭代上限失败：保留前缀和残差历史，不放宽物理/数值容差。
- 若 48 步通过但周期 oracle 失败：保留为多周期积分证据，下一实验增加周期数或审查尾迹记忆；不重定义周期收敛。
- 若必须关闭 separated LEV、改用 Q9/toy、CPU fallback 或降低真实尾迹分支次数才能通过：本实验判失败。
