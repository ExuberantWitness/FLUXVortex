# L2-1 涡通量一致性 oracle：环量源与涡通量不一致（决定性，2026-11-21）

> 工具：`platform/warp_vpm/diagnose_roj_flux_consistency.py`
> 证据：`artifacts/baselines/fluxv_v5m_rojratsirikul2011_p1_joint_validation/flux_consistency_a15.json`
> 工况：A15、joint 路径、冻结生产配置（age=100 / cap=32768）、同一物理窗 t*=3.5

## 1. 定义（全部可从求解器状态直接测量，未改求解器）

- `Γ_ribbon` = `lev_strip_last_release[strip]`（m²/s，实际沉积的每带环量）
- `U_s` = `|Γ_bound,LE| / dx_LE`（涡片强度即切向速度跳，故 bound 前缘片强度就是离散滑移速度）
- `Γ_flux` = `½·U_s²·Δt`（Kaden/Didden slug 模型，尖锐前缘每步脱落量）
- `ds` = 最新队列粒子相对**本带** LE 节点的弦向偏移均值（m）

## 2. 结果

| dt* | 步数 | \|Γ_ribbon\|/Γ_flux（step>200 中位数） | 比值最大 | ds/(U_s·Δt) |
|---|---|---|---|---|
| 0.01 | 350 | **22.9** | 17.3 | 0.185 |
| **0.005** | 700 | **48.5（≈2.11×）** | 44.8 | 0.195 |

## 3. 判读（两条独立指纹同时命中）

1. **Δt 依赖指认“环量源”**：Δt 减半 → 比值**翻倍** → `Γ_ribbon` 与 Δt **无关**，即脱落量不是由涡通量给出的，而是由与 Δt/Δs 无关的约束独立决定。这给出 `γ_recon = Γ/Δs ∝ 1/Δt` —— 文献指明的经典 runaway 机理（加密时间步反而放大片强度）。
2. **片厚度不随 Δt 伸缩**：`ds/(U_s·Δt)` 在两档下都是 ~0.19（Δt 减半而比值几乎不变）→ 沉积涡片的弦向厚度是**固定的几何比例**（约 1/5 个 `U_s·Δt`），不是物理片厚。
3. 合并效应：`γ_recon/(½U_s) ≈ (23~48) × (1/0.19) ≈ 120~250` —— 近 LE 片承载的涡量比物理值高**两个量级**，其自感应足以驱动 α=15° 的指数放大（与队列分解“爆后最新一条 ribbon 占 LE 感应 100%”完全一致）。

## 4. 结论与分支裁决（按计划第 1 步的预设判据）

**判据：`γ_recon` 显著偏离且随 Δt 变化 → 支持“环量源”机理 → 下一步走 E1-FLUX。**

因此：
- **E1-FLUX（下一步）**：每步脱落环量改用 `ΔΓ = ½·U_s²·Δt`（尖锐前缘通量律），替代“从 LE 不穿透解 newborn”。这使 Γ 由构造正比于 Δt 与 U_s²，从而**有界**，自反馈环路断开。
- E1-BUFFER-NETFILAMENT 降为**后备**：仅在 E1-FLUX 未能同时保住 α=5°（0.3425±0.003）时启用（它解决的是表示层，而本条已证明病根在环量源）。

## 5. 诚实边界

- 本 oracle 是**离散定义**下的量化（`U_s` 用 bound 前缘片强度作为滑移代理，系数 ½ 取 Kaden/Didden），不是实验测量；它证明的是“与通量律相差 1–2 个量级且随 Δt 漂移”，不是“物理上必须等于 ½U_s²”。
- 因此 E1-FLUX 实施时必须做成 flag，并以红测（A15 1000 步 `max|cn|<5`、α=5° 保持 0.3425±0.003）判定，而不是拿本 oracle 的数值当验收。
