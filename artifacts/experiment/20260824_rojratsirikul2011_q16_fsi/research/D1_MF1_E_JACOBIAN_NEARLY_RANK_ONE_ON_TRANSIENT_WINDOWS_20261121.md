# D1：2×2 退化雅可比实测 —— 三个窗口的 J 都近似秩 1，且 Mf1 列跨窗口变号（2026-11-21）

> 钩子：`FLUXV_MF1_SCALE`（`warp_fsi/q16_flux_v5m_native_fsi.py`，默认 1.0 逐位不变）
> 驱动：`/tmp/d1_probe.sh`（四个 run 的命令行与时间戳在 `/tmp/d1_probe.log`）
> 分析：`/tmp/d1_analyze.py`；原始 payload `/tmp/d1_{base,mf1,e,both}.json`
> 契约测试：`tests/test_q16_mf1_scale_hook.py`（10/10）；parity 6/6

## 1. 被测量

A16 膜翼，`dt*=0.01`，**各 200 步**（6.78 / 6.88 / 6.90 / 6.89 s/步，各约 23 min），四跑除两个参数外完全相同：

| run | `FLUXV_MF1_SCALE` | E |
|---|---|---|
| base | 1.0（未设） | 2.2 MPa |
| mf1 | 1.05 | 2.2 MPa |
| e | 1.0 | 2.31 MPa（+5%） |
| both | 1.05 | 2.31 MPa |

四个 run 统一 `FLUXV_LU_CACHE=1`（有限差分内一致；且已单独验证该缓存对 scale=1.05 逐位无影响，见 §5）。

窗口：W1 = 步 101–150（t\*∈[1.01,1.50]）、W2 = 步 151–200（t\*∈[1.51,2.00]）、Wp = 101–200。
观测量：窗口内 `Cn` 均值、`|instantaneous_zmax_over_c|` 均值。

## 3. 能确定的三件事

**① 三个窗口里 J 都近似秩 1。** 两列夹角落在 0° 或 180° 的 5° 内（W1 平行、W2/Wp 反平行），`|det|/||J||²` 全部是正交上限的 2.5%–7.9%，`cond` 25–80。
⇒ 在**这批窗口上**，`(Cn, |zmax|/c)` 这一对观测量无法把"Mf1 整体缩放"与"E 变化"分开：5% 的 Mf1 变化与 5% 的 E 变化给出几乎共线的响应向量。

**② Mf1 列在两个相隔 50 步的窗口间变号，E 列不变号。**

- `∂Cn/∂lnMf1`：**−8.363e-2**（W1）→ **+1.5023e-1**（W2）；`∂|zmax|/∂lnMf1`：−4.80e-3 → +8.76e-3。两个观测量同时变号。
- `∂Cn/∂lnE`：−1.1427e-1 → −2.7644e-1；`∂|zmax|/∂lnE`：−1.6115e-2 → −3.7028e-2。两个观测量在两个窗口都是负号，且 W2 更强。

⇒ 用 W1 拟合出的"熔 Mf1 修正系数"到 W2 会把 Cn 推向反方向；用 E 拟合的至少在符号上窗口一致。

**③ 这个 2×2 是一阶有效的，不是非线性伪影。** 同时扰动两者的实测值与该 2×2 的线性预测之差，占实际位移量：W1 为 4.0%/2.2%，W2 为 −3.6%/0.0%，Wp 为 0.9%/0.9%。5% 扰动仍在线上性区域内。

## 4. 机制假设（明确标注为假设，未单独检验）

膜翼响应是振荡的，而"窗口均值"对参数的响应同时含振幅与相位两条通道。数据与"Mf1（附加惯量）在此区间主要表现为相位移动、E 主要表现为振幅"一致：Mf1 列在**两个观测量上同时**变号，E 列在两个观测量上同时不变号。若成立，则"用一个 Mf1 系数去修膜翼"在原理上就不稳定，因为符号取决于窗口落在振荡的哪个相位。**未做相位/振幅分离的独立测量。**

## 5. 测量链路的自检（都做了，都过了）

| 检查 | 结果 |
|---|---|
| 钩子默认路径是否逐位不变 | 未设 env 的 4 步 digest 链与 **hook 之前**（`git stash`）逐位相同 |
| scale=1.0 是否返回同一对象 | 是（`is` 判等），否则会静默破坏 M1b memo / M1 缓存的 `id()` 键 |
| M1 缓存是否与 scale=1.05 的新张量交互 | 8 步 cache=1 与 cache=0 digest 链**逐位相同** |
| 非法 scale | `-1`/`0`/`nan`/`abc` 全在 import 期退出 1 |
| 契约测试 | `tests/test_q16_mf1_scale_hook.py` 10/10 |
| 生产 parity | `test_roj_unified_case_runner_parity_gpu.py` **6/6** |
| payload 自我标注 | 新增 `diagnostic_mf1_scale` 与 `is_diagnostic_branch`（未设时 1.0 / False） |

## 6. 边界（不能从这批数据得出的结论）

1. **这不是收敛窗口的雅可比。** 实验数字读出目标定义在 t\*≥20；这批窗口是 t\*∈[1,2]。runner 自己的窗口选择器在该 payload 里写的是 `stationary_window_found: false`、`window: [100,200]`。因此本记录**不用于**解 `J Δp = 残差`。
2. 收敛窗口的 2×2 需要两个全长 run（2100 步，当前 6.8 s/步 ≈ 各 4 h），未做。
3. 只测了一个工况（A16）、一个扰动幅度（5% 前向差分）、一个 Mf1 缩放方向（+5%）。未做中心差分，未测 scale<1 一侧。
4. 原始四个 payload 生成于 `diagnostic_mf1_scale` 字段加入**之前**，其溯源只有 `/tmp/d1_probe.sh` 与 `/tmp/d1_probe.log`（含每跑的命令行与时间戳）。

## 7. 与原计划的偏差（记录而非隐藏）

| 原计划 | 实际 | 原因 |
|---|---|---|
| 20 步 × 4 run | 200 步 × 4 run | 斜坡是 t\*∈[0,1] 即 1–100 步，步 20 的 `freestream_factor` 仅 0.0955，20 步窗口整个在斜坡内 |
| 300 步 | 200 步 | 6.8 s/步 ⇒ 300 步约 28 min/run；改为 200 步并在 [101,200] 内拆两个子窗口做稳定性核查，省掉第二窗口的长跑 |
| 只报 `|det|/||J||²` | 另报夹角、cond、每观测量杠杆比、一阶有效性 | 单看 det 无法区分"共线"与"某列过小"，而这两者对应不同的后续动作 |
