## 0. 这份记录的作用

它是路线 B 的**预注册决断点**（计划 S2.0）。结论是**路线 B 被否证**，且顺带纠正了我上一份笔记的两处错误。写下来是为了不让任何人（包括我自己）再花 3 小时去验证一个方向错的方案。

## 1. 方法（把真实沉积片按边组拆开）

`add_connected_ribbon_particles` 沉积的是**闭合 ribbon**：`anchor→anchor[1]` 展向片带 `+γ`、`frontier→frontier[1]` 展向片带 `−γ`、两条流向连接段带 `−(γ_i−γ_{i−1})`（`pfield_torch_gpu.py:563-574`）。净环量与净矢量矩按构造为零。

因为诱导是线性的，我把这三组边分别重建成独立粒子场（子划分规则逐字镜像内核 `:606-630`），在同一批真实 `anchor / frontier / γ_lev` 上分别求**首排配点法向感应**，并逐 σ 扫描（`spacing = σ/2.125`，恒满足冻结重叠门）：

- `w_mono` = 仅 LE 展向片（**这就是沉积片应当等效的对象：单极**）
- `w_anti` = 仅 frontier 展向片
- `w_conn` = 仅连接段
- `w_dip` = 三组之和（= 真实沉积片）

自检：`w_mono + w_anti + w_conn` 与实测 `w_dip` 逐位相符（α=15, σ=0.04：`+10.648 − 10.246 + 0.0193 = +0.4181` vs 实测 `+0.4181`）⇒ 拆分正确。

## 3. 三条结论

### 3.1 主缺陷是**幅度 1/25**，不是符号
生产 σ 下，LE 片给 `+10.65`、frontier 片给 `−10.25`，**相消 96%**，净剩 3.9%。原因是纯算术的：偶极子间距 `ds = 0.0049c` 只有站位距离 `x_c0 = 0.0601c` 的 **8.1%**，而 `1 − f(r−ds)/f(r) ≈ (ds/r)·(r f′/f) ≈ 0.081 × 0.48 ≈ 0.039`。

**这就是 L2-1 那个 `γ_lev ∝ 1/Δt` 的完整算术来源**：闭合方程要求新生片"用感应抵消 O(U∞) 的滑移"，而它的每单位 γ 感应被压掉 25 倍且 `∝ Δs ∝ Δt` ⇒ 解出的 `γ_lev` 被放大 25 倍且 `∝ 1/Δt`。

**两条独立测量的定量交叉验证**：本探针给出 `1/0.0393 = 25.4` 的抑制比，L2-1 用完全不同的方法（累计 `Γ_ribbon` 对通量律 `Γ_flux`）给出 `22.9`。两者相差 10%，且残差可由本探针已量到的有限展向端部与连接段贡献（`w_conn` 占 `w_dip` 的 4.6%）解释。⇒ 机制闭环，不是巧合。

**α=15 与 α=19 的比值几乎相同（+0.0393 / +0.0451）⇒ 该缺陷与攻角无关，是结构性的**，不是深分离特有的。

### 3.2 路线 B（成组分辨率升级）被否证
把 σ 从 0.04c 降到审计建议的 0.02c，`w_dip/w_mono` 从 **+3.9% 变成 −6.8%**：符号翻成**反单极**，幅度还涨了 1.7 倍。

- 分辨率**不可能**把一个 25 倍的幅度亏损补回来 —— 它只决定这个 3–7% 的小残差的**符号**；
- 而反单极（把表面往外推）比现状（同号但极弱）在物理上更错；
- 因此**不实施路线 B**。`σ/Δ/capacity` 三者继续冻结。

**我的预注册判据设计有缺陷，必须记录**：原判据只要求"比值在 σ 跨越 x_c0/r_peak=1 时变号"，它**确实变号了**，按字面应当进入 S2.1。但变号只是必要条件，不充分 —— 缺一条**幅度判据**（例如"变号后某一个 σ 的 `|ratio| ≥ 0.5`"）。按字面执行会让我花 3 小时把一个小而同号的残差改成一个同样小但反号的残差，属于退步。**判据已被数据推翻，路线不执行**；这条教训（预注册判据必须同时约束符号与幅度）保留。

### 3.3 生产 σ 下配点**在核峰内**，此时偶极子与单极**同号**
`r_peak(σ=0.04) = 0.0634c > x_c0 = 0.0601c` ⇒ 配点在峰内 ⇒ `f′ > 0` ⇒ `w_dip` 与 `w_mono` **同号**（+0.0393）。只有当 σ ≤ 0.032c（配点移到峰外）才反号。

## 5. 由此确定的唯一可行路线（A）及其量化目标

缺陷的正确定位是：**每一步的沉积片被永久闭合在 `0.0049c` 的跨度上**。100 步之后场里有 3000 个各自独立的小偶极子，没有一个呈现单极场。这同时解释了远场 `r⁻³` 与近场 4%。

所以路线 A 的目标不是"把 σ 调小"或"换脱落律"，而是**让回转环量远离表面**：

- 新生 LE 片必须是**开口**的（净环量 `= γ_lev`，不是 0），其后缘边与**上一排已对流的前缘**共边（与 TE 尾迹链严格镜像，共享边余弦 −1）；
- 回转路径位于片的**下游端**，随对流走到 `O(d) ≫ x_c0` ⇒ `1 − f(r−d)/f(r) → 1`，近场恢复单极效力；
- 验收指标就是本探针这一列：**`w_dip/w_mono ≥ 0.8`**（对生产几何、α=15/19、第 ≥3 步），外加原有的红测（α=15 `max|cn|<5`、α=5 `0.3425±0.003`、默认路径逐位不变）。

零向量矩闭合门（`pfield_torch_gpu.py:645`）必须从"闭合偶极子不变量"改成"开口片的净环量账本 = Σγ_lev"，且需要一个**非闭合**沉积入口（`add_particles` 直通），因为开放边必然 `Σγ ≠ 0`。

## 6. 边界
- 本记录只测了**首排配点、单条真实沉积片、第 3 步**的隔离感应；闭环增益还涉及全部 450 行的 `ribbon_basis`，未在此量化；
- α=5 在第 3 步尚无分离样本，故"角度无关"只由 α=15/19 两条支撑（α=5 的 `λ/Γ=0.36` 来自长跑，未在此复算）；
