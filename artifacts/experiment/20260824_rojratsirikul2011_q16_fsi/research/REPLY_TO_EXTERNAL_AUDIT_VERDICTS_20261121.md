## 二、你被推翻的地方

### 2.1 核内反号区的**符号反了**（方向性错误，照做会更坏）

你的原文：σ=0.04c 时 `r_peak = 0.0634c > x_c0 = 0.050c` ⇒ 首排配点落在上升段 ⇒ **核内偶极子感应与核外反号**。

实测（同一探针，逐 σ 扫描，`spacing = σ/2.125` 恒满足冻结重叠门）：

| σ/c | 配点/核峰 | `w_dip/w_mono` |
|---|---|---|
| **0.0400（生产）** | 0.947（峰内）| **+0.0393** |
| 0.0320 | 1.184 | +0.0107 |
| 0.0300 | 1.263 | +0.0009 |
| 0.0280 | 1.354（峰外）| **−0.0102** |
| **0.0200（你的建议）** | 1.895 | **−0.0678** |

**配点在峰内时，偶极子与单极同号**；移到峰外才反号。所以：

- **你建议的 `σ_LE ≤ 0.02c` 会把符号翻成"反单极"，并把幅度从 3.9% 放大到 6.8%** ——比现状更错。已实测否证（另见 2.2 的 A3 实验）。
- 另外 `x_c0` 实测是 **0.0601c**，不是 `0.75Δx = 0.050c`；因此正确的阈值是 `σ < 0.0315c`，不是 0.020c。
- 连带：你用它解释 `E1-WINDOW`（"核外尾迹在平衡核内反号项"）这句话**不成立**。`E1-WINDOW` 的现象本身（window=3 第 50 步爆炸 ⇒ 远场感应是稳定因素）是独立测量，仍然有效，但机理归因要重找。

### 2.2 TE/LE 拓扑失配不是病因

### 2.3 α=19 的 −28% **不是**缺 Polhamus 涡升力

这是整份审计里代价最大的一个归因。那个 −28% 是**无斜坡 1000 步均值**。按项目自己冻结的启动协议（`rojratsirikul2011_q16.py:174-182` 半余弦 `0→U0` 覆盖 `t*∈[0,1]`=100 步，`case_runner.py:733` 逐步施加，标 `numerical_protocol` 且排除出统计）重跑：

### 2.5 性能部分的四条机械性错误

| 你的论断 | 实测/源码 |

| BS 核 2-D 网格跨块发散，破坏合并访存 | **错**。Warp 是 1-D grid-stride，`launch_coord` 先展开 `i`（`warp/native/builtin.h:1926-1933`、`codegen.py:4604`）⇒ 相邻 lane = 相邻 **target**，target 读取完全合并，source 整 warp 广播（1.5 MB 常驻 L2）。改布局还会破坏 `torch.sum(partials,dim=1)` 的求和顺序 |

## 三、执行你的建议时发现的、审计没看到的

### 3.1 现状能"工作"是因为一个**误差相消对**

| 事实 | 来源 |
|---|---|
| 沉积片的近场效力只有单极的 1/25 | 1.2 的实测 |
| 闭合因此把 `γ_lev` 放大 ~10× | 实测 0.099×、L2-1 独立 22.9× |
| **两者乘积是 O(1)** | ⇒ 升力在未发散区间是对的 |
| 清空粒子场（每步 `n=0`）会把 cn 从 **+0.393 变到 −0.912（翻号）** | 消融实验 |

⇒ **只改表示或只改环量律都会破坏这对平衡**。这解释了为什么此前六条路线 + 你的三个建议方向（开口化、σ 变小、去 TEV 补偿）全部失败：它们都只动了平衡的一半。

顺带纠正我自己：我曾推断"粒子云在载荷上是装饰性的"，消融把这个推断打掉了——它通过 RHS/bound 环量通道显著驱动载荷。

### 3.2 三维拉伸：我实现的**不是** rVPM 式

你指出缺拉伸项后，我先实现了裸 Helmholtz 式 `dγ/dt = S`。跑出来：

| α=19 | 均值 | max\|cn\| |
|---|---|---|
| 基线 | 0.926 | 3.14 |
| 裸拉伸 | 0.861（**+7.6% vs 实验 0.8**）| **33.2** |

然后我发现仓库里**早已冻结了正确式子**（`platform/docs/diag/research_rvpm_arch.md` V4，引 rvpm-02）：

```
Z = [(f+g)/(1+3f)·(S·Γ)]/|Γ|²,  dγ/dt = S − 3Zγ,  dσ/dt = −σZ
```

`−3Zγ` 正是让被拉伸元**有界**的那一项。补上后：

| α=19 | 均值 | max\|cn\| |
|---|---|---|
| 裸拉伸 | 0.861 | **33.2** |
| **rVPM（补 −3Zγ）** | 0.976 | **5.56（压 6×）** |

代数判据（参数自由）：`Γ·(S−3ZΓ) = (2/5)(Γ·S)`，精确到 `1e-12·dt|S|`。**`Cε` 置 0 而不猜**——冻结笔记没给值，引入非零耗散系数等于引入新参数。

### 3.3 最关键的一处：裸式的爆炸不是失稳，是**数值事件**

α=19 末 22 步细结构：

| 变体 | cn | `newborn` |
|---|---|---|
| 基线 | 0.77–3.14 平滑 | 稳定 ~0.10 |
| 裸拉伸 | …+5.37, −5.42, −17.87, **−33.23** | 末三步 **5.4e-3 → 0.00 → 0.187** |
| **rVPM** | +1.92→+5.56→…→−4.92 | **全程 0.057–0.125，无事件** |

**裸式的爆炸前 `newborn` 先塌到精确 0，再放大 6 倍。rVPM 让这个失效模式不再发生。** 这比"压尖峰 6 倍"更有价值。

### 3.4 载荷双轨：不是求积误差，是**真实的 ~35% 定义分歧**

你说 `projection_quadrature_discrepancy = 0.28–0.52`，并归因为"载荷映射口径/求积"。我量化了（A16, t*=0.03，同一分母 `|packet|`）：

| 量 | 值 |
|---|---|
| `\|packet − legacy_constant\| / \|packet\|` | **0.338** |
| `\|packet − (constant+velocity+Mf1)\| / \|packet\|` | **0.383** |
| `\|legacy velocity_force\|` | 常量的 **2.7e-5**（可忽略）|
| `\|legacy Mf1 action\|` | 常量的 **32.4%** |
| 传输力闭合 / 点级功共轭 | 3.10e-24 / **0.0（精确）** |

我一度以为"0.313 ≈ 0.324 ⇒ 差异就是被比较省略的 Mf1 项、两轨其实一致"。**加进去后距离反而更远（0.338→0.383）**，我的推断被自己的数据推翻。⇒ 两条轨道是**真实的载荷定义分歧**，传输合同本身精确。所以你的第 3 阶段不是"统一口径"，而是**判定哪条轨道对**的研究决策。

而且**柔翼不能当裁判**：`(zmax, Cn)` 对"气动尺度 × 刚度尺度"退化，35% 的载荷改动正好落在退化方向上。建议用有外部真值的工况裁决（Yamano 载荷门、Izraelevitz Fig.14 CT，当前 MAE 0.0409）。
