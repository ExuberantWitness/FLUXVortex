## 2. 核心发现：环核的冻结常数

### 2.1 公式与量纲

`kernels_ring_velocity.py`，每根直涡丝的诱导速度：

```
v = Γ/(4π) · (a×b) / (|a×b|² + 1e-9) · [(a − b)·(â − b̂)] · kv
```

`a`、`b` 从涡丝两端指向场点。注释写明 `1e-9` 取自作者的 MATLAB（Yamano）。`|a×b|` 的单位是 m²，
所以这个常数的单位是 m⁴。对一根长 L、到场点垂距 h 的涡丝，`|a×b| = L·h`，
正则带来的衰减因子约为 `(L·h)² / ((L·h)² + eps)`。

Roj 路径上活着的只有两份，都在这个文件里：torch 实现 `_EPS_V`（影响系数矩阵 `native_aic` 用它）
和 Warp 融合核的 `_C_EPS_V`（其余所有环速度求值用它）。已加开关 `FLUXV_RING_EPS_V`，默认仍为 `1e-9`。

### 2.2 核函数层面：它不是尺度不变的

同一个环（面板 4.59 mm），生产核与无正则的 Biot–Savart 之比（`diagnose_ring_kernel_scale_invariance.py`）：

| 场点 | 弦长 68.8 mm（本工况） | ×10 | ×100 |

| 相邻两条带 | **0.600** | 1.0006 | 1.0000 |
| 相邻四条带 | **1.407** | 1.0008 | 1.0000 |

### 2.3 两个长度尺度（本次新增，请重点看）

`|a×b| = L·h`，所以同一个常数对不同长度的涡丝作用范围不同。
"受影响的范围"定义为 `(L·h)² = eps` 时的 h：

| 常数 | 翼面面板（L = 4.59 mm） | 尾迹沿流向的短涡丝（L = U·dt = 0.688 mm） |
|---|---|---|
| **1e-9（现状）** | 6.9 mm = **0.10 弦长** | 46 mm = **0.67 弦长** |
| 1e-10 | 0.032 弦长 | 0.21 弦长 |
| 1e-11 | 0.010 弦长 | 0.07 弦长 |
| 1e-12 | 0.003 弦长 | 0.02 弦长 |

Roj 机翼的半展长是 1 个弦长，弦长 68.8 mm。也就是说，**现状常数下，尾迹的拖曳涡丝在覆盖整个翼面的范围内都被衰减**：
翼面上配置点到各条拖曳涡丝的垂距从 1.15 mm（本条带边界）到 137 mm（对侧翼尖），
对应的衰减因子从 0.06% 到 90%。承载有限翼展下洗的正是这些涡丝。

### 2.8 我的机理解释（工作假设，请审）

1. 现状常数对翼面涡格的近场（0.10 弦长内）和尾迹拖曳涡丝（0.67 弦长内）都做衰减。
   后者覆盖整个翼展，使有限翼展下洗偏弱，于是 Cn 偏高、展向加载过平、等效展弦比偏高（约 3.5）。
2. 常数变小，拖曳涡丝的衰减先解除（它的作用范围随 `sqrt(eps)` 缩小），下洗恢复，Cn 下降并穿过实验值。
   但翼面涡格的近场同时也在变，两者不按同一比例，加上钉扎与粒子脱落的阈值效应，
   所以不同迎角不在同一常数过零。
3. 时间步依赖来自短涡丝长度 `U·dt`：步长越小，`(L·h)²` 越小，同一常数下衰减越强。
4. 扑翼对常数更敏感，可能因为扑翼的推力更依赖尾迹诱导速度与非定常载荷项；这一点我没有分解数据。

### 2.9 未解释的现象

**生产解在常数 ≤ 1e-11 时低于定常直尾迹涡格。** 5°：生产 0.1742（1e-11）、0.1525（1e-12），
定常涡格 0.2203、0.2194；而 1e-9、1e-10 两者相差只有 0.3%–3%。已排除：

- 尾迹方向：把定常涡格的直尾迹整体倾斜 10°，Cn 只变 0.25%，三个常数下相同。
- 尾迹强度与近场形状：生产在 1500 步末，排间距 0.0100–0.0115（名义 0.0100），
  无折回上游节点，尾迹环量 newest / oldest / 尾缘行三者一致（定常）。

已排好一个直接检验（膜翼扫描之后自动跑）：把生产在 5°、常数 1e-12 与 1e-10 的末帧完整状态存盘，
在 CPU 上用同一核函数重组线性系统，检查**生产自己的环量在该系统里的残差**，并把实际尾迹换成直尾迹重解。
残差在舍入量级则问题在尾迹实际形状；残差很大则生产求解路径里另有东西。脚本：
`diagnose_production_state_resolve_cpu.py`。

### 3.2 joint 臂全长发散的机制（A15）

LESP 涨 7 倍。生产路径里这个量为 0，不受影响。

## 5. 请分析的问题

1. **机理是否成立。** §2.3 的两个长度尺度，以及 §2.4 的时间步依赖，是否足以解释：
   Cn 偏高、展向加载过平、不同迎角过零点不同？计划 L3 的验收门里写着
   "步长减半（dt\* = 0.01 → 0.005）脱落环量收敛阶为 O(1)（打破现行 22.9 → 48.5 的 1/Δt 发散）"，
   这个 1/Δt 发散与本发现是否同一机制？
2. **无正则的涡格为什么只有薄翼理论的 0.80 倍。** 一个标准的涡格法应接近 1.0。
   是离散格式（闭合环、配置点在环心、均匀间距、15×30）、尾迹表示（直尾迹 3 弦长），还是别的？
   在标定任何参数之前，`eps → 0` 的解能否作为参考？
3. **生产解在常数 ≤ 1e-11 时偏低 21%–31%**（§2.9）。已排除尾迹方向、强度与近场形状。还剩什么？
4. **扑翼推力在常数 ≤ 1e-10 塌陷**，而前缘涡脱落步数不变。哪一项主导：尾迹诱导速度对配置点的影响、
   非定常载荷项、还是短涡丝长度（扑翼的 `U·dt` 与 Roj 不同）？
5. **LESP 判据的标定基础。** 判据的输入是前缘那一行的环量除以 `c·U·(θ+sinθ)/1.13`，
   它随常数从薄翼理论 A₀ 的 1.83 倍变到 0.48 倍。`lesp_crit = 0.11` 与扑翼工况的 `0.2393`
   是在哪个涡格上得到的？修正常数之后判据要不要重新推导，用什么定义（Hirato 的最前一根丝，还是别的）？
6. **修法与验收。** 尺度一致的正则应怎么定义（例如以面板边长与 `U·dt` 为参考，或干脆去掉并对共线求值单独处理）？
   计划 L3 的门（`w_dip/w_mono ≥ 0.80`、dt 收敛 O(1)）是否足够，还要不要加"dt 减半 Cn 变化 < x%"这类门？
   L3 是否应提前，并与本修法合并？
7. **对计划本身的修订建议。** §1 的三条更正改变了精度线的起点（膜翼 +38% 而不是 +22%）。
   在常数问题处理之前，A3c、A4-3slot 四工况全长、A5 这些精度项是否应暂缓？
