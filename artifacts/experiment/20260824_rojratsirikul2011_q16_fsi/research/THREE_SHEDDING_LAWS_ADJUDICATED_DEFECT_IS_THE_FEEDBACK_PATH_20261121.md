# 三条脱落律全部判完：缺陷不在"脱落量"，而在"反馈路径"（2026-11-21）

> 证据：`net_filament_feasibility_a{5,15,19}.json`、`kelvin_probe_a{5,15}.json`、`flux_mode_a15_a5_1000step.json`、`flux_consistency_a15.json`
> 工况：刚翼 AR=2、U=5、joint 路径、冻结配置；爆前稳态窗（步 280–300）

## 1. 三个角度上"脱落量 vs bound 前缘环量"

`Γ_bound,LE` 在三角度完全相同（0.03420 m²/s）——因为它被钉在 `crit·scale`，而 `scale` 只含几何（首格弦长/弦长/θ）。变化的全是脱落量：

| α | λ_solved（max，m²/s）| λ/Γ_bound,LE | net/target | `λ_Kelvin`（= −ΔΣΓ_bound 中位）|
|---|---|---|---|---|
| **5** | 0.0147 | **0.357** | −1.357 | **0（精确）** |
| 15 | 0.0813 | 2.159 | −3.160 | **0（精确）** |
| 19 | 0.0929 | 2.616 | −3.634 | —（同型）|

（`ΣΓ_bound` 中位：α=5 为 0.611、α=15 为 0.877 m²/s，**逐步不变**——bound 解已达定常。）

## 2. 三条脱落律的判决

| 候选 | 关键证据 | 判定 |
|---|---|---|
| **① 解出式闭包**（现状：LE pin + LE 不穿透）| A5 达 **+0.35%**；A15 步 635 后发散；`λ/Γ` 随 α 从 0.36 增到 2.6 | **唯一能复现低攻角实验的模型**，但持续分离下不稳定 |
| **② 通量律** `½U_s²Δt`（E1-FLUX）| 全程有界（newborn 7.09e3→4.28e-2，`max|cn|`=1.18），但 A5 **+9%**、A15 **+29%**（系统性过预测升力）| **不采用**（flag 保持 OFF）|
| **③ 环量守恒** `λ=−ΔΣΓ_bound`（E1-KELVIN）| 两角度 `λ_Kelvin` **恒为 0**（bound 已定常）| **退化/否证**：会冻结全部脱落，LEV 消失 |

## 3. 由此得到的结构性结论

1. **"稳定且定常的 bound 解 + 持续脱落"是本模型的既有形态**，而且它在 A5 恰好给出正确升力（+0.35%）。因此**不能用任何公式去改脱落量**——改成通量律就过预测，改成 Kelvin 就零脱落。
2. **失控只发生在 A15/A19**，那里 `λ/Γ` 是 A5 的 6–7 倍。结合队列分解：
   - 爆前 LE 感应由**累积老尾迹**主导（older 26%、6–10 排 25%、4–5 排 22%，最新带仅 3%），老尾迹平均距离 1.3c；
   - 即：**远处的累积尾迹通过 RHS 参与锐前缘的 LESP/不穿透约束**，把 λ 一步步抬高，形成反馈。
3. 所以缺陷在**反馈路径**：锐前缘的局部分离判据不该由 1.3c 外的累积尾迹主导。这正是 VoFFLE 保留"近场缓冲、远处转粒子"的真实理由——**不是为了消除几何重叠**（0.13–0.17σ 已被文献判定无害），而是为了**限定进入前缘约束的感应窗口**。

## 4. 队列改道（第二次，仍由测量驱动）

- 取消 **Step 3（BUFFER-NETFILAMENT）**：已否证（`d849d9b`）；
- 取消 **Step 3′（E1-KELVIN）**：本轮否证（稳态退化为零脱落）；
- **新增 Step 3″：E1-WINDOW（窗口化前缘反馈）** —— 保留解出式闭包与 LE pin，**只把 LE 闭合方程 RHS 中的粒子感应限制在近场窗口内**（例如 birth_step 最近 N 步，或距 LE ≤ k·c 的粒子），远处尾迹仍完整参与**非 LE 行**与载荷计算（物理不丢，只是不让远场主导局部判据）。
  - 这是对 RHS 的作用域修改，**不是**改脱落律、**不是**调系数、**不是**阈值扫描；
  - 红测：A15 `step≥2 max|cn| < 5`；A5 保持 `0.3425±0.003`；窗口宽度作为**敏感性/收敛性**单独报告（N 与 k·c 各取两档），不用于挑最优。
  - 判据：若存在某个窗口使 A15 有界且 A5 不变 → 反馈路径假设成立；若两个窗口都无效 → 反馈不走粒子感应，转查尾迹环（`wake_rings`）的对应贡献。

## 5. 边界
- `λ_Kelvin` 的中位为 0 只说明 bound 总量逐步不变（定常），不说明模型正确；
- LESP 目标符号仍用 `sign(Γ_bound,LE)` 作离散代理，实现 E1-WINDOW 时须用有向单位基复核；
- 本记录纯诊断，未改任何生产数值。
