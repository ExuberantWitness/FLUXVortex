## 2. 因此 A6 的表述要改成

- A6 的 18.5% 是**轨迹级灵敏度**：置零尾迹后，150 步里膜的运动与分离轨迹本身改变了，窗口均值随之差 18.5%。**它不是"瞬时载荷里尾迹占 18.5%"**。
- 同理 A6 的"粒子占 0.3%"也是轨迹级量；**瞬时**粒子项占 0.53%。
- 两条结论里**只有"LEV 粒子不是主因"这一条仍然成立**（瞬时 0.53%、轨迹级 0.3%，量级一致且都很小）。

## 3. 更正后的方向：+22% 在"束缚载荷模型"里

瞬时 rhs 99% 由运动学项决定 ⇒ 偏差只能来自把 rhs 变成载荷的那条链：

1. `native_aic` 的构造/归一；
2. 载荷投影（KJ 点力 vs 5P 求积）；
3. 运动学项本身的归一（`v_inf`、`normals`、`q·S`）。

其中 (3) 已部分排除：`q·S = 0.142846 N` 与 `c·b`、AR=2.00 都对过；`v_inf = 5.0 m/s`、`ρ = 1.208` 来自 case spec 的 `paper_printed` 字段。

## 4. 独立异常：环量账本不闭合

```
sum gamma_bound   = +11.868
sum wake_gamma    = +14.846      ← 同号，且比束缚环量大
bound + wake      = +26.714      ← 相对 |bound| 的残差 2.25
sum particle circ = +2.4e-16     ← 精确 0（偶极沉积）
```

闭合涡系统的束缚 + 尾迹总环量应满足 Kelvin；实测残差是束缚环量的 **2.25 倍**。可能与 `wake_gamma` 的存储约定（每行 = 环量 vs 每片段 = 强度）或符号约定有关，**未查证**。

与既有结论的关系：沉积的 LEV 云是**精确零环量偶极子**（2.4e-16），所以"不平衡"不是沉积造成的；它要么是尾迹环量的定义问题，要么是报告口径问题（`gamma_bound_sum` 与 `wake_gamma.sum()` 不是同一量）。
