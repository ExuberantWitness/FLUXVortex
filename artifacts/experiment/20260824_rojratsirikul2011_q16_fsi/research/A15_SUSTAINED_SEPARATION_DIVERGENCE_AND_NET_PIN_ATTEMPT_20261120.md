## 3. 机理假设（未验证）

当前 joint pin 是 `Γ_le = s·κ_crit`（把 bound 前缘环量单独钉在临界值）。
Bird et al. (2021) 式 (14)/(17–19) 的分离约束作用在**净前缘丝**上：

```
Γ_bound,first − λ_first = s·κ_crit
```

只钉 `Γ_le` 意味着：已释放的 LEV 环量 λ 持续累加，但约束不要求 bound 环量随之下降，于是
LEV 感应增长 → 不穿透要求更大的 bound 环量 → 又释放更多 LEV。这与观测到的“尖峰递增 → 指数爆炸”一致。

## 4. 一次失败的修复尝试（已回退，代码不在仓库中）

实现：增广系统 `[[A, B], [E, −I]]`，pin 行改为
`Γ_le − δλ = s·κ_crit + λ_prev`，其中
`λ_prev` = 上一步沉积的 ribbon 粒子的 `circul` 按 `source_strip` 求和后取负（因为
`_deposit_dvm_ribbon` 传入的是 `−gamma_lev`）。保留全部 P 条不穿透行（pin 行是**追加**而非替换）。

结果：**从第 2 步起就指数发散**，比原实现更糟：

```
cn      : 0.814, 1.205, 1.635, 2.085, 2.568, 3.091, 3.717, 4.472, 5.569, 7.157, 12.827 …
newborn : 0.156, 0.214, 0.263, 0.386, 0.643, 1.003, 1.883, 3.724, 6.831, 11.813, 23.978 …
```

第 60 步时自检 `|net_filament − target| > 1e-6` 抛错（说明该增广系统在某些步已病态或
约束本身不自洽）。代码已 `git checkout` 回退，未提交。

### 失败原因的最可能解释（下一轮必须先判掉）

**双重计入**：已经释放的 LEV 粒子感应**本来就在不穿透 RHS 里**（`particle_velocity` 项）。
若约束再要求 `Γ − λ = crit`，等于把 λ 的贡献在“感应”和“约束”两侧各算一次。正确的离散形式应是：
从**同一组不穿透方程**出发，决定未知量是**绝对 λ** 还是**增量 δλ**，并让 RHS 只保留未被 λ 表示的那部分场
（这正是复核报告 Q-A 的“条件恒等式”，并明确指出“不能直接把 q 改写成 q_n−q_{n−1}”）。

另外两个必须先确定的量：`λ_first` 的几何定义（最新一排 ribbon，还是近 LE 缓冲区内全部 LEV），
以及粒子 `circul` 的求和是否等于该条带的 γ_lev（ribbon 是分段分摊还是逐粒子全额）。

## 5. 下一步（带验收条件，按序）

1. **导出符号/尺度约定表**：对一条静止平板 + 一次已知释放，验证
   `Σ_p circul_p == −γ_lev_strip`（分摊方式）、`source_strip` 的索引语义（条带 ns 还是节点 ns+1）、
   以及 λ 与 Γ 是否同一单位的数值核对（打印两者量级）。
2. **写出不双重计入的约束**：在固定材料历史 S_n 下，把“净前缘丝 = 临界”写成一个只含
   **本次未知量**的方程（绝对 λ 或 δλ 二选一），并用解析小算例验证其与 `[A B]` 行不冗余。
3. **红测**：在 A15 上，newborn 强度自查必须满足 `max|δλ| < 10·max|Γ|` 且 1000 步内
   `|cn| < 5`；否则判失败，不得进入统计。
4. 通过后再谈 A15/A19 的精度（当前 A19 均值 −28%，A15 在 t*<6 已接近实验）。
