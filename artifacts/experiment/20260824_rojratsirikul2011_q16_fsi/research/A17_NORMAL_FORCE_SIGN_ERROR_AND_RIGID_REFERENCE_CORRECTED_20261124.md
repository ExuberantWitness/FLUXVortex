## 1. 法向口径的符号错误（runner）

`case_runner.py` 的 `force_coefficient_conventions` 昨天写成

    normal = (−Fx·sinα + Fz·cosα) / (q S)

注释取翼面法向 `n = (−sinα, 0, cosα)`。这是**往上游倾**的法向，对应一个尾缘朝上的翼。

实际情况：来流沿 +x，迎角烧进参考网格，**尾缘向下**（弦向 `(cosα, 0, −sinα)`），
翼面法向是 `n = (sinα, 0, cosα)`，于是

    Cn = (Fx·sinα + Fz·cosα) / (q S) = CL·cosα + Cx·sinα        （即 N = L cosα + D sinα）

**证明不靠读几何，靠力的方向**：A16 收敛窗实测合力
`F = (0.0380, 0, 0.1782) N`，从竖直方向往**下游**倾 12.05°。平板的压力合力只能落在
翼面法向附近，所以法向必然朝下游倾。（往上游倾的法向会给出一个朝上游倾的合力。）

| 量 | 值 |
|---|---|
| CL = Fz/(qS) | 1.2472 |
| Cx = Fx/(qS)（顺流） | 0.2663 |
| Cn 正确 = CL cosα + Cx sinα | 1.1990 + 0.0734 = **1.2724** |
| Cn 旧式 = CL cosα − Cx sinα | 1.1990 − 0.0734 = 1.1256 |

**后果**

* 膜翼 A16 论文口径的 Cn 误差由"+22%"更正为 **+34% ~ +38%**（对 0.95 ~ 0.92）。
* "差距的三分之一是口径"（11-23 的 A16 笔记、提交 `622d59a` 的标题）**撤回**。
  口径（升力 vs 法向）只差 2%（1.2472 vs 1.2724）。
* `zmax/c` +3.3% 通过门的结论不受影响。
* LE-pin 三臂的 E 评分用的是同一个错式子：三臂同尺，**名次不受影响**；
  但 E 的绝对值不再等于"对论文口径的误差"。
* 已修（只改报告量与门，不动模拟）。红测 `tests/test_roj_unified_case_runner_parity_gpu.py`
  **6/6 通过**（37.4 s，19:13）。
* 既往 payload 里的 `mean_cn_normal` / `h9_mean_cn_normal` 是错值；
  可用其中已存的 `mean_force_x_n` / `mean_force_z_n` 按正确式子重算。

## 4. 一个不依赖实验的基准：附着薄翼理论

AR=2、椭圆加载：`Cn = 2π·AR/(AR+2)·sinα`

| α | 5° | 10° | 15° | 16° |
|---|---|---|---|---|
| 理论 | 0.274 | 0.545 | 0.813 | 0.866 |
| 实验（刚性，数字化） | 0.1985 | 0.4508 | 0.700 | 0.7431 |
| 模型（刚性） | 待测 | 待测 | 待测 | **1.0982** |

* 模型的刚性 A16 比附着理论高 **+26.8%**。把它代回椭圆公式反推，相当于 AR≈3.5 的机翼。
* 分离 / LEV 模型应当把力压到附着值**以下**（实验 0.7431 < 0.866），
  它解释不了"比附着值还高 27%"。
* 所以 Cn 超量的主嫌疑**不在 LEV、不在膜**，而在两种翼共有的气动环节：
  有限翼展下洗偏弱（尾迹 / 翼尖 / 侧缘涡），或 AIC 归一化（A7 的独立校验两次都无效，
  算子仍未验证）。A9 测到的"翼尖环量不降为零"与此同向。

"等效 AR≈3.5"只是量级表述，不是归因。
