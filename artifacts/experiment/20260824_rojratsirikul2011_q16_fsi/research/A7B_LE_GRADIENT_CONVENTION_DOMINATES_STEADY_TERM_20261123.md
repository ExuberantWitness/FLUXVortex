## 1. 载荷的构成（法向，步 150 提交态，闭合到 0）

生产载荷 = `author_load.constant_pressure × areas × normals`（`q16_flux_v5m_native.py:1912-1913`），而

```
constant_pressure = dp_lift1 + ρ·mf2_history
dp_lift1          = ρ · Σ (U∞ + 尾迹 + 粒子 + 束缚诱导) · ∇Γ       （q16_flux_v5m_author_loads.py:543）
```

| 分量 | `Fn/qS` | 占比 |
|---|---|---|
| **`dp_lift1`（定常，∝ ∇Γ）** | **+0.9916** | 76.7% |
| `mf2`（非定常，∝ ΔΓ/Δt） | +0.3013 | 23.3% |
| 合计 | +1.2929 | 100% |

**定常项单独就已比论文中心值 0.92 高 7.8%**，再加非定常项到 +40%（此为步 150 瞬态提交态；收敛窗均值是 +22%）。

## 2. ∇Γ 的前缘写法（`q16_flux_v5m_native.py:1830-1832`）

```python
dx_gamma[0]  = grid[0] / dx[0]                  # 前缘：隐含 Γ(x=0)=0
dx_gamma[1:] = (grid[1:] - grid[:-1]) / dx[1:]  # 后向差分
```

束缚片的起点在 **x = 0.25·dx**（`assemble_native_ring_geometry`，`rear = quarter[-1] + 4/3·(TE−quarter[-1])`），不是 0。所以"Γ 从 0 升到 Γ[0] 发生在多长距离内"是一个**约定**，而 `dp_lift1` 正比于它。

## 3. 四种约定的实测（同一提交态，只改前缘那一行）

| 前缘约定 | 定常项 `Fn/qS` | vs 现行 |
|---|---|---|
| **现行** `Γ[0]/dx` | **+0.9916** | — |
| 按真实间距 `Γ[0]/(0.25dx)` | +0.4597 | **−53.6%** |
| 中心差分到 0 `2Γ[0]/dx` | +0.8143 | −17.9% |
| 不假设前缘奇异 `(Γ[1]−Γ[0])/dx` | +1.9005 | **+91.7%** |
| 分母换 `dx[:-1]`（与约定无关的核对） | +0.9945 | +0.3% |

重算值与仓库 `dp_lift1` 逐位相同（+0.99161）⇒ 复现的是同一条公式。

## 4. 含义与边界

**含义**：A16 的 +22% 现在有了第一个**具体的、可定位到一行代码**的嫌疑点——前缘梯度的离散约定。它与此前所有排除项一致（诱导速度项是二阶量、Mf1/Mf2_1 合同不是杠杆、口径已修 9.76%）。

**边界（必须随数字一起引用）**：

1. **这不是调参入口。** `quarter` 虽把定常项降到 0.46，但加上 mf2 后总计 ≈ 0.76，**低于**论文带 0.84–1.00。选哪个约定必须由**作者原始定义**决定，不能按"哪个对得上论文"来选。
2. **只改了提交态的代数，没有重跑。** 前缘梯度同时进入 `external_flow·∇Γ`（载荷）与时间推进（γ 会重新分布；LESP/分离判据也可能受影响），所以真实效应需要一次 150 步 A/B。
3. 薄翼理论里前缘 ∂Γ/∂x 本就**奇异**；任何离散都在选一个等效值。现行 `Γ[0]/dx` 等价于"Γ 在 0→0.75dx 上线性上升到 Γ[0]"，与几何起点 0.25dx 不自洽——**这一点是客观的**，哪种自洽写法正确取决于作者源码。
4. 单工况、单状态（步 150 提交态）；收敛窗上的占比未测。
