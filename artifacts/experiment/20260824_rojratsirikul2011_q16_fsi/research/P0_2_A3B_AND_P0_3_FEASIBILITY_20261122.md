## P0-2：`1.4×` 是分母假象，我的 A3 结论错了

A16，t\*=0.12，把 legacy 三槽拆开（柔度范数 / 扳手合力）：

| 分量 | 柔度范数 | 相对常量 | 扳手合力 | 相对常量 |
|---|---|---|---|---|
| legacy **常量** | 0.368847 | 1.000 | 0.033140 | 1.000 |
| velocity 槽 | 0.000442822 | 0.12% | 7.51e-07 | 0.002% |
| **Mf1 槽** | 0.102638 | **27.8%** | 0.0092944 | **28.0%** |
| legacy **三槽和** | 0.268679 | **0.728** | 0.023845 | **0.720** |
| 5P 包 | 0.389276 | **1.055** | 0.0347182 | **1.048** |

- **5P 包对 legacy 常量只差 5.5%（柔度）/ 4.8%（扳手）**，不是 1.4×。
- 三槽和只有常量的 **0.728 / 0.720** ⇒ Mf1 槽反向扣减 27–28%，`1/0.72 ≈ 1.39` 正是先前测到的 1.45。
- velocity 槽可忽略（0.12%）⇒ 全部来自 **Mf1**，与 `bound_rate` 双算一致。
- 结论更正为：**不是 5P 过报，是 legacy 三槽轨被 Mf1 压低 ~27%**。"不能只换常量槽"仍成立，但理由改为"迁移会把已知的 −27% Mf1 缺陷搬进新轨"。

## P0-3（S3-v2A）：单元局域性 —— 实测确认，31× 的数量级成立

`platform/warp_vpm/diagnose_tangent_element_locality.py`（A16，真实 mesh，`dof=2976`，`element_count=50`，`local_dof=96`）：

| 检查 | 结果 |
|---|---|
| 只喂 element 0 的单位方向 | 作用量非零项 **恰好 96 个，支撑正好是 element 0 的块** |
| 喂 element 0 与 31 | 非零 **192 个**，支撑是两块 |
| `action(0+31) == action(0)+action(31)` | **True**（`torch.equal`，逐位） |
| 单批 64 方向耗时：局部布局 vs 全局布局 | **176.9 ms vs 176.5 ms（相同）** |

第 4 行是关键，也是我一开始误读的地方：两者**每批代价相同**，说明 element operator 的成本与方向稀疏无关（对 `(64, 50, 96)` 稠密跑）。所以省的不是"每批更便宜"，而是"**批数从 47 → 2**"：

- 现行：47 批 × 176.6 ms = **8.30 s/次刷新**（实测每批 176.5–176.9 ms）
- 提议：96 个局部方向 = 2 批（64+32）× 176.9 ms = **0.354 s/次刷新**
- **23.5×**（按批数 47/2；按列数 2976/96 = 31 是你给的数，两者差在最后一批只装 32 个）
- 刷新频率 0.13 次/步 ⇒ **1370.6 → ≈58 ms/步**，省 **≈1.31 s/步**

**验收必须用容差，不能声明逐位**：局部块按 `_connectivity` 散加进 2976² 全局阵，累加顺序与内核的 node-occurrence 求和不同，浮点加法不可结合 ⇒ 相对误差 ~1e-14 量级。落地时必须：
1. 用容差与现行 2976 列探测的切线对比；
2. 保留线性残差门与非线性残差门（它们仍是接受判据）；
3. 单 flag 门控、可回退。

## P0-1（S0-bench 快照）：按现规格**不能做**

仓库里没有 checkpoint/restart 设施：
- `NativeV5MState` 只有 `clone()` / `digest()` / `mutation_fingerprint()`，无序列化/恢复；
- `CudaParticleField.snapshot_numpy()` 是"显式序列化边界，从不用于时间积分"（注释原文），只导出**活跃行**的 8 个字段，且没有任何路径把它注回一个重建的 runner；
- `Q16NativeStructuralCheckpoint` 只是结构子步内的内存对象；
- runner 没有 `--resume`。

所以 P0-1 是一项**新代码任务**（序列化 ~10 个状态张量 + 粒子场，并写恢复路径），不是一个 2.5 min 的测量。
