# A6 载荷归因（消融）：膜翼 +22% 全部来自**尾迹环诱导**，LEV 粒子只占 0.3% —— 否证"LEV 表示是主因"（2026-11-23）

> 开关：`FLUXV_ZERO_INDUCED` ∈ {`particles`, `wake`, `both`}（默认空 = 生产路径不变）
> 数据：`/tmp/cnconv_150b.json`（full）、`/tmp/abl_{noparticles,nowake,both}_150.json`
> 方法：消融而非线性拆分 —— `L∘A⁻¹` 在 rhs 层线性，但下游 LESP 钉扎非线性，载荷级叠加不闭合；置零后跑完整非线性路径

## 1. 结果（A16，150 步窗口，`t*∈[1,1.5]`）

| 臂 | `mean cl` | `mean cn_normal` | `Fz` (N) |
|---|---|---|---|
| full | **1.0184** | 0.9022 | 0.1455 |
| no-particles | 1.0202 | 0.9040 | 0.1457 |
| no-wake | 0.8303 | 0.7384 | 0.1186 |
| **both（纯运动学+束缚）** | **0.8327** | 0.7407 | 0.1189 |

归因（法向/升力口径一致，这里用 cl）：

```
运动学 + 束缚        0.8327   (-9.5% vs 论文 0.92)
+ 尾迹环诱导        +0.1881   (+20.4% vs 论文)
+ LEV 粒子          +0.0024   (+0.3%  vs 论文)
= full              1.0184   (+10.7%；收敛窗上为 +22.3%)
```

## 2. 三条结论

1. **LEV 粒子项对载荷的贡献 0.3%** ⇒ 「近场 1/25 × 闭合 10× 相消对」**不是膜翼 +22% 的来源**。项目早期"清空粒子场 cn 从 +0.393 翻到 −0.912"是**刚性翼**现象，不能外推到膜翼。**L3（前缘涡环缓冲链）作为精度主因的假设，被这一步否证。**
2. **超出的部分全部来自尾迹环诱导（+20.4%）**。纯运动学+束缚项已经落在论文带（0.84–1.00）下沿附近（0.8327，低 0.9%）。
3. **尾迹项的符号存疑**：经典升力线理论里尾迹下洗**降低**有效迎角与升力，这里却把升力抬高 20%。两种可能：(a) 尾迹环的法向诱导符号/量纲有问题；(b) `wake_gamma` 的符号或喂给 `_ring_velocity` 的环量约定有误。**这是下一步唯一的单点检查。**

## 3. 下一步（单点、便宜）

在同一个状态上打印：
- `wake_velocity · normals` 在配点上的符号分布与量级（应主要为负 = 下洗）；
- `wake_gamma` 的总和与符号（TEV 脱落应满足 Kelvin：`Σγ_bound + Σγ_wake = 0` 的离散形式）；
- 若 `wake_velocity·n > 0` 为主，则符号错，修正后 +20% 的偏差应当直接消失或反号。

已有工具可复用：`diagnose_roj_circulation_ledger.py`（环量账本）与 `wake_gamma_sum`/`gamma_bound_sum` 两个 payload 字段——后者在 A16 全长 payload 里是 `wake_gamma_sum ≈ +0.76e-3`、`gamma_bound_sum` 在 `aerodynamic.bound_circulation_total`。

## 4. 边界

- **150 步启动窗**（`t*∈[1,1.5]`）。收敛窗（`t*≥20`）的三项占比未测——但方向（粒子 ~0、尾迹为主）由机制决定，不太可能反转；需一次全长四臂才能定量（4 × 3.9 h，未做）。
- 消融改变了轨迹本身（不同臂的膜运动不同），所以是"同窗口的机制归因"，不是严格的线性叠加。
- `no-wake` 臂仍保留 `aic` 里的**束缚片自诱导**（那是 AIC 矩阵的一部分，不是 `wake_velocity`），所以"纯运动学+束缚"这个名字是准确的。
- 单工况、单次运行。
