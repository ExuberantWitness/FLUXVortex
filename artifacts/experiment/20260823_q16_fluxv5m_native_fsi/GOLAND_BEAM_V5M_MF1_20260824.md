## Mf1 实现

FLUX-V5M 附加质量以质量矩阵修改方式实现（非外力）：
```
m_eff = m_struct + ρ·π·(c/2)²      [heave added mass per span]
I_eff = I_struct + m_add·c²/24     [torsional added inertia]
```

这是正确的隐式格式——附加质量降低固有频率、不引入人工阻尼。
颤振速度从 140.2 上移到 142.7 m/s（+1.8%），方向与经典颤振理论
一致（质量比增大 → V_f 上移）。

## 关键发现

1. **KJ-only 失败证明了尾迹项的必要性**：L=ρVΓ 不含尾迹诱导速度
   → 零气动阻尼 → 全速域不稳定。这正是 FLUX-V5M 压力分解中 Mf2
   （尾迹历史项）的物理意义。

2. **Mf1 必须以质量矩阵形式实现**：作为外力滞后施加（即使只滞后一步）
   会引入人工阻尼（σ≈−0.47 vs 结构阻尼 −0.25），淹没颤振机制。
   质量矩阵化（M_eff = M + M_add）是唯一正确的隐式格式。

3. **附加质量使 V_f 上移**（140.2→142.7）：m_add=3.22 kg/m ≈ 结构质量
   9%，有效惯性增大 → 固有频率降低 → 需更高流速达到颤振耦合。
   与经典颤振理论的质量比效应一致。
