# Q16 ↔ 原生 FLUX‑V5M CUDA FSI 实施计划

## 目标

在 Yamano 2020 `single_sheet_u25_m1_ar1` 正式工况上建立唯一生产依赖：

`Q16(5×3) 结构 ↔ 原生 FLUX‑V5M CUDA(15×10) 气动`

运行时禁止 Ptera、Q4、Q9，以及由它们生成载荷或推进状态的任何包装器。MATLAB/Q4/Ptera 数据只可作为离线 oracle，不可进入时间积分。

## 冻结科学合同

- 坐标：论文科学坐标，`+x` 弦向/来流下游，`+y` 展向，`+z` 厚度方向。
- 结构：共享节点 Q16 MITC16/EAS 壳，5×3 宏单元；不建立 Q4/Q9 中间模型。
- 气动：15×10 面板；Q16 表面直接生成 1/4 弦环涡和 3/4 弦配置点。
- 分离：separated LEV 从 step 0 即为必选机制；物质释放条件固定为 `|LESP| > Lcrit`，`Lcrit=0.11`。
- 尾迹：LEV、joint TEV、自由尾迹与 predictor/corrector 共用一个可回滚事务；trial 不得污染 committed state。
- 载荷：面板压力/力在 CUDA float64 上形成，并直接通过 Q16 形函数转置映射；不得先投影到 Q4。
- 设备：全部科学张量必须驻留同一 CUDA GPU；不允许 CPU 数值 fallback。

## 实施顺序

1. 用作者 150×150 AIC 离线 oracle 锁定原生 V5M 环涡方向、面板顺序和法向。
2. 增加生产依赖门：新入口及其递归导入闭包不得出现 `pterasoftware`、`*ptera*`、Q4/Q9 载荷模块。
3. 实现原生表面几何、AIC/RHS/环量、面板力、DVM LEV、joint TEV 与自由尾迹 CUDA 状态。
4. 实现显式 clone/propose/commit/rollback；校验 rejected trial 对 LEV/TEV/wake/gamma 哈希零污染。
5. 通过 Q16 CUDA 高阶形函数直接传递面板载荷，并校验虚功、总力、总矩闭合。
6. 接入 Q16 Newmark predictor/corrector；先跑正式网格 1 步，再按 2/4/8 步推进论文 CASE。

## 2026-08-23 正式复现执行顺序

1. 正式 CASE 入口先读取 `YAMANO_Q16_NATIVE_LOAD_GATES.json`；AIC、Mf2、Qf 合力或 Mf1 物理符号任一硬门失败才非零退出。
2. `Qf_p_global` 只包含 `dp_lift1 + Mf2_history`，外层 `ΔΓ/Δt` 不再与子步 `Mf1` 重复。
3. `Mf1` 作为结构 Newton/Newmark 子步中的加速度作用项；`lift2/Mf2_1` 随实时结构速度更新。
4. 9-DOF 作者 ANCF 与 6-DOF Q16 的 `Mf1` 共同场差异保留为诊断警告，不再冒充离散无关的硬门。
5. 直接运行正式 5×3 Q16/15×10 V5M 一步工况，以端点响应、耦合残差及事务推进作为兼容的端到端 oracle；真实失败出现后再做针对性修复。
6. 使用 CUDA reference-dense 准牛顿加速结构迭代，每个已提交外步刷新缓存；若连续两次残差增长超过 5%，立即切换实时 GPU 切线并启用残差下降线搜索，否则最迟第 48 次切换。允许最多 128 次修正，但达到原 `3e-7` 实时 Q16 非线性残差即立即停止，不改变模型、网格、时间步或物理参数。
7. 每完成一个外步即写 `.partial.json`，后续真实失败不得抹掉已经完成的论文检查点。

## 效果检验节点

- N0 依赖纯度：生产导入闭包 Ptera/Q4/Q9 命中数为 0。
- N1 原生 AIC：正式 15×10 平板 AIC 与作者 oracle 在冻结符号/排序下达到 float64 预设容差。
- N2 GPU 所有权：几何、AIC、环量、LEV、TEV、wake、压力、Q16 状态/载荷全部 CUDA float64。
- N3 释放合同：`|LESP|≤0.11` 不释放，`|LESP|>0.11` 才释放；不能通过开关绕过 LEV 模块。
- N4 事务合同：两次同输入 trial 位精确；rollback 后状态哈希不变；commit 仅推进一次。
- N5 传递合同：Q16 虚功、总力与总矩闭合；不存在 Q4/Q9 中间自由度。
- N6 CASE 入口：5×3 Q16/15×10 V5M 一步非零退出门全通过，随后记录 2/4/8 步误差。

## 当前载荷门结果

- AIC 相对误差：`3.0073528848739746e-07`，通过 `1e-6` 门。
- `Mf2_vec1` step1–4 最大逐面板绝对误差：`3.8163916471489756e-17`，通过 `1e-13` 门。
- `Qf_p_global` step1–4 合力最大相对误差：`0.0028941429731128726`，通过 `0.005` 门。
- Q16 `Mf1` 厚度向共同加速度场功：`-0.02585925156893745`；作者 oracle：`-0.04127802486316853`；两者均为负，物理符号通过；跨离散共同场相对差 `0.3735346675462884` 记为警告。
- 结论：硬门允许 N6 正式执行。已有 655.96 秒、误差 15.81% 的旧输出因载荷路径不同仍不视为当前实现证据。

## 明确废弃的路线

`reproduce_yamano2020_q16_fsi.py` 当前 Ptera/Q4 运行时以及 2026-08-23 的坐标修补只保留为失败诊断；不得将其数值或测试通过状态称为原生 V5M FSI 成果。

## N7：作者同轨迹 → Q16 GPU 恢复力判别

- 基线固定为 `YAMANO_Q16_5X3_V5M_15X10_STEP8_AUTHOR_LOAD.json`，不得改变网格、时间步、材料、Lcrit 或误差定义。
- 用作者公开 MATLAB 程序只读生成同一 `Nx=15, Ny=10, d_t*=0.002, U*=25, M*=1` 的 `t*<=0.55` 完整状态轨迹；该 CPU 程序只产生离线 oracle，不能进入 Q16/FLUX-V5M 生产求解。
- 将作者 9-DOF 曲面在正式 Q16 节点处按作者形函数采样：位置取作者曲面位置，Q16 厚度 director 取局部 `dx_r × dy_r` 单位法向乘 `h/2`。所有 Q16 内力、能量和切线评价在 CUDA float64 上执行。
- 在 `t*=0.068/0.136/0.204/0.272/0.544` 比较作者轨迹上的 Q16 恢复力功/能量增长，并与刚完成的 Q16 FSI 状态比较。若第4步前已出现系统性欠恢复，修复Q16本构/积分；否则返回同轨迹气动力分量。
- 任何候选修复先通过正式状态判别，再重跑同一个1/4/8步 CASE；禁止经验缩放和新的简化工况。
