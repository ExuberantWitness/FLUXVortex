## 2. 发现并修复的四个确定性实现 bug

所有 bug 均在 `RigidAuthorLoadAssembler` / `RigidNativeV5MSolver` 路径中——这是 H3 中新写的力提取层，从未在真实 CASE 上运行过。V5M 求解器内核（AIC、γ、wake、粒子）未被触碰。

### Bug 1：lift2 / Mf2_1 压力项漏乘密度 ρ

**位置**：`rigid_flux_v5m_native.py:195`（刚性路径）+ `q16_flux_v5m_author_loads.py:344`（Q16 路径）

**现象**：四个压力分量中两个乘了 ρ、两个没乘，然后直接相加——Pa 与 m²/s² 量纲混合。水 ρ=1000 → 运动相关载荷被压低 1000 倍。

**修复**：补乘 `self.density`。提交 `55916e0`。

**回归门**：ρ=1.0 vs ρ=1000.0 时所有压力分量必须严格线性缩放。

### Bug 2：bound_rate 用了 Γ(n-2) 而非 Γ(n-1)

**位置**：`q16_flux_v5m_native.py:1018`

**现象**：`(Γ_n - gamma_previous) / dt` 中 `gamma_previous` 因状态更新顺序实际持有 Γ_(n-2)，导致 `dp_add = (Γ_n - Γ_(n-2))/dt` 而非正确的单步差分——非定常载荷谐波幅值近翻倍 + 相位偏移。

**修复**：读取 `trial.gamma_bound`（在 propose 内该时刻仍持有 Γ_(n-1)）。提交 `55916e0`。

**回归门**：三步运行，验证 mf2_history == (Γ_2 - Γ_1)/dt 精确成立。

### Bug 3：力投影用 p·A·n̂（零弦向分量）

**位置**：`rigid_flux_v5m_native.py` RigidAuthorLoadAssembler 整体

**现象**：压力×面积×法向投影的推力方向分量为**零**——附着流中推力物理上不可能被预测（因为推力 = Kutta-Joukowski 弦向力）。这解释了 v1/v2 低相位条件推力符号翻转。

**修复**：替换为 Pterra 已验证的 Kutta-Joukowski 环线力积分：每面元 4 条环线 `ρ·Γ_eff·(v_sol - v_grid)×dl` + 非定常 Bernoulli `ρ·Δγ/dt·A·n̂`。提交 `4656b6b`。

**回归门**：(a) 纯升沉时 p·A·n 给 Fx≡0 但 KJ 给非零推力；(b) 稳态 +5° 翼 KJ 升力与独立压力投影差 <0.15%。

### Bug 4：LEV 释放双 owner 冲突（2D source bank 独立决定释放）

**位置**：`q16_flux_v5m_native.py` propose() + `ldvm_source_bank_gpu.py` step()

**现象**：3D LESP 和 2D source bank 各自计算 LESP（来自不同环量状态），在同一时间步对同一条带给出矛盾的分离/释放判定。15° 族 1300-1500 步冲突/条件。

**修复**：给 source bank 的 `step()` 添加 `cell_release_mask` 参数——2D 释放决定被 AND 门控于 3D 真值：`release = raw_2d_trigger AND mask`。3D 说"未分离"的条带永远不能释放。提交 `b71d81b`。

**效果**：冲突 1490 → 0（全部 12 条件）。门控主动抑制 1420-2550 次/条件的虚假 2D 释放投票（`release_gate_overrides`），且高 ψ 无分离条件为 0（物理选择性，非一刀切）。

## 4. 剩余差距归因（bias +0.031，2.2× 门）

### 假设 A：势流类模型边界（最可能）

历史 V2（MAE=0.0175）用的是 `enable_lev=False + prescribed_wake=True + post-hoc LDVM ΔCT 修正`。这**不是**一个纯 V5M 结果——它是附着流底盘 + 手工修正的混合体。

当前 v4 是**首次用集成 LEV + 自由尾迹的纯 V5M 路径**跑此 CASE。势流类模型（无黏性）在深失速区缺少：
- 黏性分离损失（profile drag 增大）
- 前缘泡效应（降低有效环量）
- 尾迹卷起的黏性耗散

这些缺失会导致推力过预测，与观测的 bias=+0.031 一致。

### 假设 B：Cd0 值不匹配

论文用 Cd0=0.057（Izraelevitz Fig.14 约定），但 Scherer 实测 Cd0=0.027。如果有效 Cd0 应更高，我们的 CT 会偏高。

### 假设 C：网格分辨率

当前 8×24（每半翼 12 展向），历史 V2 用相同网格。分辨率不可能是主要因素（两路径同网格，历史达到 0.0175）。但收敛检查仍有价值。

### 假设 D：非定常 Kutta-Joukowski 在大振幅扑翼中的近似误差

KJ 力提取在小扰动下精确，但 h/c=0.6 + θ_max=25° 是**大振幅**。有限展长 + 大攻角 + 大升沉的联合效应可能使 KJ 近似偏低/偏高。
