## 1. 已确认的模型缺陷与修复(全部第一性原理)

### 1.1 faure 附着阻力门 bug(已修,cfg `faure_gate_pre`)
hirato 隐式 LESP 约束把 post-solve A0 **精确钉在 a0_crit**,旧门 `|A0|<=crit` 把分离条带误判为附着
→ 静态翼型极曲线的二次桶 `(α_rel/12°)²` 在扑动行程 α_rel~40° 时爆成假阻力。
实测:tw22.5° 工况 faure 分量 +3.10N(kelvin 路径同工况仅 +0.21N)。
修复:门用 PRE-constraint `A0pre` 严格 `<`。效果:tw22.5 T −7.24 → −4.34(dT −6.58 → −3.68)。

### 1.2 vnf 深失速无饱和(已修,cfg `vnf_sat`)
`π·(A0pre²−crit²)` 旋转力对 A0pre 无界;饱和于 Polhamus/平板极限
`½·k_v·sin²α_eff·|cosα_eff|`,k_v=2π/(1+2/AR)(NASA TN D-4739,几何解析,非拟合)。
注:P1 实测 max|A0pre|=0.504(并非爆炸),饱和是正确物理但**不是**过冲主因(主因是 1.1)。

### 1.3 TEV 核半径污染 Kutta(已修,更早)
WAKE_CORE 误用于 solve/force 中的 TEV → Kutta 软化,基线 C_L 掉 30%。
修复:TEV 在 solve/force 近奇异,WAKE_CORE 仅用于对流。

## 3. 已知残差(如实报告,不拟合)

### 3.1 U=6 频率无关 offset(+3.4N,当前最大推力残差)— P1c 已归因
单变量分解(U6/f2.0,nc4):`H2 ≡ gate_only`(饱和零作用),`old ≡ sat_only`(T −0.12,
T_faure −1.07)→ **倒退 100% 来自 faure 门修复**:旧门 bug 在钉住(分离)条带上给的
−1.07N 附着极曲线阻力恰好占位了真实分离阻力,但它是量纲巧合(cd0·(α/12°)² 二次桶),
不是物理。分量表证明 U6/tw0 时 vnf/bern 均无弦向投影(平板法向 X 分量≈0,物理自洽),
吸力斜率已与实测一致(1.61 vs 1.37 N/1.2Hz)→ **剩余 offset 不属于翼模型类内任何项**。
实测 U6 曲线按 T=T₀+a·f² 拟合的静阻截距 ≈−3.7N,模型静阻(D_para U² 外推+诱导)≈−1.9N:
差 ~1.8-2N 为 rig 静阻在低 U 的标度问题(d_para=3.0 标定于 U8;平板 Cd 无法在 U6 长 2.7×)
→ **已知未知,如实报告,不拟合**。U6 推力 MAE ≤2.5 门在红线内不可达。
