# P2 Step-0: three_mat 分区探针判读(2026-07-05)

目的:S0 根因复核——刚度分区(碳梁条 30%/70% 弦 + 7 肋 + 膜基底单独标定)能否稳定 FSI。
改动:`_v2_flex_robo.run_fsi` 加 `three_mat` / `pre_tension` 直通(照 `E_override` 诊断参数先例)。

## 判读

1. **分区不救稳定性**:标定把膜基底压得更软(0.32 vs 2.13MPa),膜区面外 Dk 更趋零,发散更暴烈。确认 S0 结论(壳范式内重分配 E 无解),S1 真梁 + S2 张力场膜必要。
2. **病灶不需要扑动**(D1):8m/s 静态气动载荷单独即在首窗压塌膜区。机理:面外刚度趋零的膜 + **线性隐式一步推进(无 Newton、无载荷 ramp-in)**,首窗全载荷一步过冲 ~5m 出物理域。真实膜承压靠"张力×曲率"非线性机制,需首平衡迭代或增量加载。
3. **预张力在该路径完全无感**(D3 与无预张力逐位同轨),与 S0 五点扫描(N0=0..10000 同发散)一致。
4. **新增 S3/S4 设计要求**:柔性 FSI 冷启动需**载荷 ramp-in 或静态 Newton 首平衡**,否则即使结构对了,首窗一步全载荷仍可能过冲。
