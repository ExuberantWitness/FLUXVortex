# D1 Fig18 曲线身份审计（2026-07-27）

## 裁决

旧 D1“实测 `dT/dU > 0`、V4.1 `dT/dU < 0`”不成立。病因不是气动公式，
而是 `repro_data.json` / `repro_compare.json` 将 Fig18 推力曲线的 U=6 与
U=10 身份互换。

源论文 `researchpaper/Meng2025_Drones_FlappingTwist_RoboEagle_SOURCE.pdf`
第 17 页 Fig18(a) 的图例和曲线同时表明：

| 条件 | 源图标记 | f=1.4 Hz 推力（约） |
|---|---|---:|
| U=6 m/s | 绿色三角，上方曲线 | -1.14 N |
| U=8 m/s | 红色圆，中间曲线 | -2.27 N |
| U=10 m/s | 黑色方，下方曲线 | -3.17 N |

论文正文也明确说明：固定频率时，风速增加导致阻力显著增加、净推力降低。
Fig18(c) 虽采用不同颜色顺序，但图例仍将上方推力族标为 U=6、下方族标为
U=10；旧数据资产同样反标。Fig18(b)/(d) 的升力身份正确，不修改。

## 数值指纹

修正前，测量三点（f=1.4 Hz, tw=22.5°, AoA=5°）被解释为
`T(U6,U8,U10)=(-3.171,-2.275,-1.140) N`，得到
`dT/dU=+0.508 N/(m/s)`。

修正后为 `(-1.140,-2.275,-3.171) N`，得到
`dT/dU=-0.508 N/(m/s)`。V4.1 同线为
`(-0.030,-0.470,-1.133) N`，`dT/dU=-0.276 N/(m/s)`：
趋势同号但斜率偏弱，真实病灶是量级不足，不是反号。
