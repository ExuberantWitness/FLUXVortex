# N3 空间 LEV 状态与结构载荷可辨识性裁决（2026-07-27）

## 0. 问题边界

目标不是再找一个能把周期总升力拟合正确的标量，而是判断 N3 下一代闭合能否同时服务：

1. 当前刚性翼 Figure 17/18/19 的总力验证；
2. 后续质量分布、刚柔分布和运动规律的气动—结构协同设计；
3. 逐面板压力、翼根弯矩、扭矩、局部应变和气动功的可追溯传递。

本轮只改写 claim 和预登记验证门，不改变 V4.1 气动公式、常数、默认相位或 118 基线。

## 1. ① 病因：总力闭合不等于全翼载荷闭合

### 1.1 数据指纹

- Meng 实验用根部六分量天平测得 `Fx/Fz` 并做周期平均；论文没有面压力、应变场或
  PIV 涡位置数据。该数据可约束全机平均力，不能唯一约束 `p(x,y,t)`。
- N3 当前每条带只有 `A0/f2/Tv` 标量记忆。D3--D5 已证明这些标量随深扭转仍单调，
  无法表达论文报告的上表面 LEV → 附着剪切层 → 下表面 LEV 拓扑迁移。
- D7/D8 表明运动学相位是一阶敏感量；即使 `-90°` 恢复 lift 的峰后下降，thrust
  和峰位仍不对。故“换相位”不能替代 LEV 载荷状态。

### 1.2 数学不可辨识性

若一个条带只保留环量和一阶矩

```text
Gamma = integral omega dA
x_c   = integral x omega dA / Gamma
z_c   = integral z omega dA / Gamma
```

则有无穷多个不同的 `omega(x,z)` 具有同一 `Gamma,x_c,z_c`。它们的二阶矩、离翼高度、
涡核尺寸、与束缚涡/尾缘涡的距离均可不同，从而产生不同的表面诱导速度和压力分布。
同理，只约束合力和合力矩也不能唯一反演面板载荷。对结构模型，这些场可产生相同总力，
却产生不同的局部弯矩、扭矩和应变。

**病因挂树：**

- `N3.1h`：缺少 `Gamma + 位置/运动`，是总力闭合的必要改写方向；
- `N3.1h2`：把有限涡量矩状态当成唯一面压力重构器，命题为假；
- `N3.1i`：面向 co-design 缺少空间涡片/等价场状态和逐面板压力端口。

可动空间仅限 N3.1 的 open/partial 子树。N1、N3.2、N3.3、N4 的 validated
公式和簿记边界不动；N3.1f 的既有生产 rVPM 路线仍是 dead-end，不因本裁决复活。

## 2. ② 学科机理

### 2.1 LESP 只负责起涡/供给

Ramesh 等的 LDVM/LESP 谱系把 LESP 用于判断前缘脱涡并求新增涡量；已形成涡的强度和
位置随后独立对流。Narsipur 等又表明分离后黏性 LESP 可回落到近零。因此 `A0`
可以触发事件或约束新生剪切层供给，不能直接作为整个 LEV 生命周期的持续正力幅值。

### 2.2 LEV 力需要强度、位置和运动

冲量和 vortex-force 文献共同表明，涡载荷不仅依赖环量，还依赖涡相对翼面的空间位置、
运动及其与边界/其他涡结构的相互作用。三维扑翼还需要处理跨展向输运、翼尖涡连接和
涡环角冲量。由此可得到两种不同用途：

- `Gamma + centroid/velocity` 的低阶状态：适合总力归因、影子模型和快速筛选；
- 空间涡片/涡量基或与之等价的诱导速度场：才有资格通过非定常 Bernoulli/Kutta--Joukowski
  生成逐面板压力。

### 2.3 最接近当前 UVLM 的生产路线

Hirato 等的有限翼 LEV 涡片方法保留束缚 UVLM，同时显式表示前缘涡片；LEV 通过诱导速度
和 `dGamma_LEV/dt` 进入非定常 Bernoulli 表面压力，再由面元压力生成力和力矩。这比在
UVLM 之后附加一个总涡力更适合结构载荷，因为输出仍然位于气动面板上。

但该路线不能原样宣布适用于全刚度设计域。Gehrke 与 Mulleners 的柔性翼实验显示，
适当柔性可使相干 LEV 被贴体剪切层取代，过柔时还会出现后移或压力面涡结构。也就是说，
co-design 的状态拓扑必须允许 `attached / separated-sheet / coherent-LEV / opposite-surface`
切换，不能假设每个工况始终有一个固定的 LEV 点涡。

### 2.4 气动到结构的守恒传递

气动面板压力先形成 `f_a`，再映射到结构自由度。若结构位移到气动网格采用
`u_a = H u_s`，则载荷必须采用共轭映射

```text
f_s = H^T f_a
```

从而保证虚功/功率 `u_a^T f_a = u_s^T f_s`。不得先求总力，再按面积、刚度或经验权重
分摊；那会把待研究的质量/刚度设计变量反过来污染气动力定义。

对大转动、大变形和刚柔分布共同设计，`H` 一般不是常矩阵。更一般地，设气动网格
坐标由结构广义坐标和几何设计变量决定：

```text
x_a = g(q_s, d_g),           J_as = partial g / partial q_s .
```

离散虚功要求

```text
delta W_a = f_a^T delta x_a
          = f_a^T J_as delta q_s
          = Q_s^T delta q_s,

Q_s = J_as^T f_a .
```

因此 `H^T` 是线性、小变形或当前构形线性化下的特例；非线性 co-design 应保存当前
构形的功共轭雅可比。质量分布 `d_m` 进入结构质量矩阵，刚度分布 `d_k` 进入内力和
切线刚度；两者通过变形和速度反馈改变气动几何与 LEV 演化，但不得作为事后压力
分配权重。

这一恒等式现已成为可执行守卫。`claim_runtime/work_conjugate_transfer.py` 只接收
气动力积分点、点力和当前构形 `J_as`：

- 对任意随机广义虚位移直接比较 `delta_q^T Q` 与
  `(J delta_q)^T f_a`；
- 用三平移/三转动刚体列证明 `J^T f_a` 同时恢复合力和关于任意原点的合矩；
- 线性矩阵重排严格退化为 `H^T f_a`；
- API 不存在质量、刚度、面积权重或目标应变参数。

四项单测均通过。故窄义代数命题 `N3.1i2a` 可
`validated/frozen`；实际柔性梁/壳的当前构形 Jacobian、双向时间推进和耦合能量
稳定性另挂 `N3.1i2b=open`，父节点仍为 partial。

统一压力的窄义代数也已独立冻结为 `N3.1j3a`：

```text
delta_p = rho * (V_t dot grad_s(mu) + sum_k d(mu_k)/dt)
f_panel = delta_p * area * normal .
```

`unified_panel_pressure.py` 在合成逐面板数据上精确复现冻结 N1 的
`dGamma/dx,dGamma/dy,dGamma/dt` 公式，并把 Hirato Eq.17 的 bound/LEV 势跳率
作为具名压力通道先相加、只成力一次。4 项测试同时覆盖压力/力 ledger、保留通道身份
和到 `J^T` 的端到端守恒。该公式身份可 validated；真实 DDE 场提供何种
`mu/V_t` 仍由 `N3.1j2/j3` 的空间门控制。

运行时现有独立 profile `n3_spatial_shadow`，按真实子 claim 拓扑执行：

```text
N3.1j4 P2 spatial state
  -> N3.1j3 unified panel pressure
  -> N3.1i2a work-conjugate transfer
```

若 canonical field gate 未通过，下游两个节点都返回 `blocked`，且 ForceLedger
保持空；合成通过只能验证接口，不会成为生产晋升证据。由此“树即运行时计算图”已覆盖
这一新方向，不再只是文档标签。

### 2.5 DDE 片上速度与材料拓扑的二次文献裁决

Krebs 2021 学位论文全文消除了此前对“DDE 是否也需要经验核”的歧义。其有界性
不是单个三角元的无条件属性，而是**全局装配命题**：

1. 相邻 DDE 的二次势跳必须连续，公共边的等效反向线涡相消；
2. 前缘和自由端的势跳规定为零；
3. 尾缘非零势跳连续进入新生 wake，不能成为未配对边；
4. 每个表面三角元的 4 个流动切向配点位于质心和“质心到三个顶点的 90%”
   内点，不在奇异边上；
5. 诱导速度使用 Johnson NASA CR-3079 的闭式高阶 doublet 影响系数，而不是给
   Eq. 3.2 面积分加有限 `epsilon`。

这改变了实现方向。`distributed_doublet.py` 的普通离面 Gauss 积分仍只是方程
oracle，并继续拒绝源面内部点；片上路径另行实现为严格的 sheet-average 算子：
先把二次 doublet 恒等改写为定向边界涡和
`\(\boldsymbol{\gamma}=\nabla_s\mu\times\boldsymbol n\)` 面涡量，再对面积项做
Cauchy 主值的径向有限部消去。该路径没有有限偏置、核半径或排除圆盘。共面但不属于
owner 面元的点使用带符号子三角延拓，避免相邻面元在高阶配点附近退回近奇异离面积分。
它是 CPU 方程参考算子；生产候选仍须实现 Johnson 递归闭式/GPU 等价算子，并通过
相同的极限与装配证明，不能靠减小有限偏置成为生产自对流器。

同时，Bramesfeld & Maughmer 2008 的 DVE 不能被误称为“所有边界均参数自由”：
连续内边的对数正则项会相消，但外部 wake 边仍使用正则常数 `k`，文中算例取半展长
的 1%；片内未定义的切向诱导速度被数值置零。这不否定抛物 `Gamma`—线性涡片基
函数，却证伪“稳态 DVE 可原样成为非定常 LEV 材料面生产内核”。该命题已冻结为
`N3.1j1a=falsified`。

由此新增两个可执行窄门：

- `N3.1j4a`：`QuadraticDoubletAssembly` 要求每条外露边显式标记为
  `zero` 或成对 `interface`，逐边检查 P2 trace、几何重合和内部连续性。任何非零
  未配对边都会阻断统一压力和结构传力，不能用涡核掩盖。运行图同时要求 4 点/面
  Krebs 内点上的片上平均速度达到预登记求积收敛。
- `N3.1j4b`：`newborn_material_wake_band` 用前一/中点/当前三行势跳构造
  P2 新生 TEV/LEV 面带。时间中点行是求解器必填输入，禁止隐藏线性插值；生成后
  势跳随材料点保存，几何拉伸不改 Kelvin 身份；`TEV/LEV_SUCTION/LEV_PRESSURE`
  拥有不同拓扑标签。`MaterialWakeHistory` 进一步要求相邻时刻带在时间、边几何
  和完整 P2 势跳上逐项连续；多带接缝进入同一个全局 `zero/interface` 装配。

28 项 DDE 单测现覆盖基函数、全局边界、耦合缝、离面场、片上主值、共面外点、
显式中点新生行、多时刻材料接缝和 Kelvin。片上算子有四个独立证据：

1. 常强度 doublet 在片上严格退化为定向三角涡环；
2. 二次强度 owner 面结果随求积阶收敛；
3. 共面外点有限部与双侧离面极限一致；
4. 多 patch 装配与同一连续全局面的速度一致。

但 `N3.1j4a/j4b` 仍为 partial：尚缺 Johnson 递归闭式/GPU 生产算子、束缚面时间
中点解和 canonical 自由 roll-up。测试通过不能越级替代这些物理门。

### 2.6 静态场 canonical 门与顶点速度 NO-GO

在任何卷起动画、压力或 RoboEagle 总力之前，先冻结
`dde_canonical_field_cases.yaml`。制造片取
`\(\mu=x(1-x)y(1-y)\)`，因此四条外边界的 P2 trace 严格为零；网格为
`2×2/4×4/8×8` 方格的双三角剖分。一次运行结果保存在
`dde_canonical_field_results.json`：

| 守卫 | 结果 | 预登记门 | 裁决 |
|---|---:|---:|---|
| 常强度 doublet—三角涡环相对误差 | `4.98e-15` | `<=1e-10` | GO |
| 对称点切向速度占比 | `4.83e-17` | `<=1e-10` | GO |
| `z=8→16` 远场衰减指数 | `2.99494` | `[2.7,3.3]` | GO |
| 离面网格 Cauchy 比 | `22.55` | `>=2` | GO |
| 片上网格 Cauchy 比/最细相对变化 | `19.13 / 1.18%` | 单调且 `<=12%` | GO |
| 全局连续/零边界/材料 Kelvin | 全通过 | 全通过 | GO |

因此只把 `N3.1j4d`（CPU 静态场 oracle）窄义晋升为
`validated/frozen`。这不等于 Johnson GPU 生产算子，更不等于动态卷起、压力或力。

随后对“4 个内点速度如何移动共享 wake 顶点”做组成部分隔离。Krebs 只写明
“wake vertices with their local velocities”，没有给出边缘极限离散式；NASA TP-2995
则指出单面 doublet 速度在 panel edge 依赖趋近方向。第一次候选把内点速度恢复为
全局连续 P2 节点场，在 `2×2` 网格得到 `rank=23<25`，故
`N3.1j4c0=falsified/frozen`：继续只能添加未取证的正则或任意零空间约束。

正确的空间身份要区分“P2 势跳”和“P1 平面几何”。第二候选
`sheet_velocity_projection.py` 把 4 点/面的 sheet-average 速度以无正则最小二乘
投影到跨接口焊接的连续 P1 几何速度：

- 任意仿射/刚体速度在顶点和面内以 `2e-14` 量级精确恢复；
- 不相邻 patch 只通过显式 `interface` 焊接，禁止按距离猜接缝；
- 二次速度内容留在 residual，不被投影悄悄吸收；
- rank 不足直接失败；
- 切向规范明确登记为 sheet-average，而非把某一侧速度当作材料速度。

这 6 项只验证离散投影身份，故 `N3.1j4c1` 仍为 partial。下一门必须是自诱导材料片
的时间/网格收敛和 Kelvin 保持；未通过前不能把 P1 投影接成生产自由卷起器。

### 2.7 动态门两次 NO-GO：全矢量连续投影是错组件

第一次动态预登记
`dde_material_advection_cases.yaml` 使用零边界平面制造片。解析刚体旋转的 Heun
误差比为 `3.99974/3.99993`，Kelvin、P2 trace、边界和网格质量均通过；但自诱导
时间 Cauchy 比仅 `1.88056<3.0`，镜像残差 `1.62e-4>1e-10`。事后诊断发现：

- 同向对角线剖分本身不具镜像对称；
- 势跳 trace 连续不蕴含边中点涡量连续；该片的最大涡量跳为 `0.04419`；
- 这正对应 Krebs §3.3 在公共边额外施加两项涡量/梯度条件的组成部分。

没有放宽旧门。第二次在运行前冻结
`dde_cylindrical_advection_cases.yaml`，改用周向闭合、旋转对称、起始即非共面的
圆柱片，并取精确轴向二次势跳 `mu=y(1-y)`。结果：

| 守卫 | 结果 | 门 | 裁决 |
|---|---:|---:|---|
| 旋转网格等变误差 | `4.44e-16` | `<=1e-10` | GO |
| 刚体 Heun 误差比 | `3.99974/3.99993` | `>=3.8` | GO |
| 自诱导时间 Cauchy 比 | `1.91929` | `>=3.5` | NO-GO |
| 48→64 阶变化/位移 | `1.06%` | `<=2%` | GO |
| 连续 P1 全矢量投影残差/输入 | `53.97%` | `<=30%` | NO-GO |
| 面积/边长/Kelvin | 通过 | 通过 | GO |

因此网格对称和二维求积均不是剩余主犯。错误命题是把三维 sheet-average 全矢量
强迫为一个连续 P1 顶点场。Ambrose 的 Birkhoff--Rott 结果只保证法向速度连续；
切向速度跨片有跳跃，并含参数化自由。由此
`N3.1j4c1=falsified/frozen`，下一节点 `N3.1j4c2` 必须拆开：

1. 只把内点法向 sheet-average 速度投影到共享 P1 顶点法向，用于几何形状演化；
2. 切向分量作为显式网格重参数化规范；
3. 若切向规范改变节点标签，P2 势跳必须以守恒方式重表达，不能一边改参数化一边
   声称 face-local `mu` 原值就是材料 Kelvin。

两份失败 JSON 均保留，禁止把圆柱对称性通过误写成动态卷起通过。

第三次 `dde_normal_advection_cases.yaml` 只把全矢量投影替换为全局 P1 法向标量
投影。独立法向 ODE 的 Heun 比值 `3.896/3.948` 通过，但圆柱自诱导仍得到
`time Cauchy=1.9175`，法向拟合残差 `56.61%>20%`。因此
`N3.1j4c2=falsified/frozen`。被证伪的是“整个高阶法向场属于全局 P1”，不是
“形状由法向速度决定”。

Krebs Fig.3.6--3.7 的 90% 内点设计是让多个严格内点围绕共享顶点，使局部法向条件
在顶点邻域受约束；它没有要求四点/面的速度全局降阶为 P1。下一
`N3.1j4c3` 因而改为顶点星局部极限：在每个顶点的一环面元内，以严格内点法向速度
作无正则局部仿射外推，只取顶点截距。该路线若 rank 不足或动态时间门不通过就失败，
不得增加 ridge、核半径或经验邻域半径。

顶点星门运行后，局部条件数 `5.80`、顶点/样本速度比 `0.802`、旋转等变和网格均
通过，但时间比仍为 `1.911`。因此 `N3.1j4c3=falsified/frozen`；三种顶点映射得到
`1.919/1.918/1.911` 的同一指纹，足以排除映射为剩余主犯。

剩余分支来自初始网格：圆柱每个轴向四边形的两个三角形严格共面，共有 16 条此类
内部对角边；法向运动一步后四点一般不再共面。于是同一源面对在 `t=0` 走共面有限部，
在任意 `t>0` 走非共面单侧极限，离散 ODE 不是光滑自治场。新
`N3.1j4c4` 只给相邻轴向环加入半个周向网格的相位差，使所有初始内部边具有非零
二面角，同时保持离散旋转等变、势跳、步长、求积和阈值不变。该隔离已在
`dde_nonzero_dihedral_advection_cases.yaml` 运行前冻结。

### 2.9 N1 条带强度到连续 P2 新生行：C1 展向闭合 GO

N1/LESP 接口每条带只给一个强度，而含 `ns` 个条带的 P2 新生行有 `2ns+1`
个展向节点。仅把条带强度写到各单元中心会留下 `ns+1` 维零空间；任何最小曲率、
滤波或正则都将引入没有文献身份的权重。Krebs §3.3 给出的内部强度/梯度连续条件
提供了缺失方程。对镜像半翼，采用：

```text
每个条带 P2 中点值 = N1/LESP 条带强度                 ns 条
内部条带边界左右一阶导数连续                           ns-1 条
根部镜像对称：d(mu)/ds = 0                              1 条
自由翼尖：mu = 0                                        1 条
```

总计 `2ns+1` 条方程，恰好对应 `2ns+1` 个 P2 节点；系统中不存在平滑参数。
运行前冻结 `dde_span_trace_cases.yaml`，在 `ns=4/8/16` 的均匀网格和
`s_i=(i/ns)^1.3` 拉伸网格上使用制造解 `mu=1-s^2`：

|---|---:|---|

| 最大条件数 | `497.26` | GO |
| 制造 P2 节点最大误差 | `2.33e-15` | GO |
| 中点/根导数/尖端/内部导数残差 | `<=7.11e-15` | GO |
| 三时间行生成的材料带内部 trace jump | `0` | GO |

### 2.10 N1 AIC—DDE 新生片三 stage 耦合：代数 GO，物理网格门未过

```text
AIC * Gamma_b = rhs_without_new_LEV - I_DDE * Gamma_LEV
A0 = observer(Gamma_b,front)
A0(active strips) = sign(A0_pre) * LESPcrit
```

其中 `I_DDE` 的每一列不是常强度环，而是 `N3.1j4b1` 给出的一个单位条带中心、
全局连续 P2 半翼新生片；其诱导速度由无核 DDE 边降维算子直接投影到 N1 配点法向。
该联立关系是仿射的，因此无需增益、阻尼或压力目标。

## 3. ③ 方向裁决：缺组件，不是旧标量排序错误

| 候选 | 总力 | 面板载荷 | 宽刚度域拓扑 | 裁决 |
|---|---|---|---|---|
| `A0/f2/CV/CNv` 重新组合 | 可调 | 不可辨识 | 无 | 已由 D3--D5 证伪 |
| 每条带 `Gamma + centroid` | 可闭合/可归因 | 弦向仍不唯一 | 弱 | 只准诊断/筛选 |
| 少量二维点涡 | 可给冲量 | 压力依赖额外反演 | 固定拓扑 | 不作生产主线 |
| UVLM + 有限翼 LEV 涡片 + 面板 Bernoulli | 可 | 可 | 需增加拓扑状态 | 首选生产研究方向 |
| 全 rVPM/粒子替换生产链 | 理论可 | 可 | 可 | 本仓既有实现已 dead-end，禁重走 |

因此，正确改写不是“给 LEV 涡量矩状态添加一个全翼分配器”，而是：

```text
A0/LESP onset & feed
        ↓
spatial LE shear-layer / LEV state
        ↓ induced velocity + dGamma/dt
UVLM bound solve + panel unsteady pressure
        ↓
panel force ledger
        ↓ H^T
structural nodal load
```

全局/条带涡量矩状态保留为该空间场的降阶观测量和守恒 guard，不是载荷生成的唯一状态。

### 3.1 面向 co-design 的状态分层

本节的推导目标是回答：在质量分布、刚柔分布和运动规律同时变化时，什么状态有资格
生成结构载荷。组织推导的不变量是气动—结构界面的离散虚功，而不是总升力。
推导状态为 **COHERENT AFTER REFRAMING**：有限涡量矩仍可作为总力 ROM，但必须把
“结构载荷生成器”重构为空间气动状态到面板压力的前向问题。

令气动面板载荷为 `f_a in R^(3 N_a)`，根部六分量合力/合矩为

```text
w = B f_a,        w in R^6 .
```

这是精确线性簿记。由于实际 `3 N_a >> 6`，`B` 存在高维零空间；任取
`delta f_a in ker(B)`，都有 `B(f_a + delta f_a)=w`。因此，从正确的总力/总矩
反演唯一面板载荷在数学上不成立。增加有限个涡量矩只会减少零空间，除非状态维数和
物理闭合足以确定诱导速度/压力场，否则仍不能消除非唯一性。

把 LEV 空间状态记作

```text
q_LEV = {X_e, Gamma_e, connectivity_e, topology},
m_LEV = C(q_LEV) = {Gamma, centroid, second moments, ...}.
```

其中 `X_e/Gamma_e/connectivity_e` 是涡片或涡环单元的位置、强度和连接关系，
`topology` 区分贴体剪切层、相干 LEV、脱落和压力面涡。`m_LEV=C(q_LEV)` 是从
空间场到有限矩的多对一观测，不存在无需额外假设的唯一逆映射 `C^-1`。

合格的载荷生成链为

```text
q_LEV
  -> induced velocity at aerodynamic panels
  -> bound-circulation solve and local dGamma/dt
  -> delta_p(panel,t)
  -> f_a(panel,t)
  -> f_s = H(q_s)^T f_a .
```

最后一步是共轭载荷传递。若 `u_a=H(q_s)u_s`，则

```text
u_a^T f_a = u_s^T H(q_s)^T f_a = u_s^T f_s .
```

所以质量/刚度不能进入一个事后“气动力分配权重”；它们应通过结构变形 `q_s` 改变
气动几何、LEV 空间演化和耦合矩阵 `H(q_s)`，再由物理压力自然改变载荷分布。

由此形成三层状态，而不是二选一：

1. **生产载荷状态**：可对流的有限翼 LEV 涡片/涡环或等价空间基，负责面板压力；
2. **低阶观测状态**：条带 `Gamma/centroid/second moments`，负责总力归因、
   守恒 guard、控制器观测和快速筛选，不直接分配结构载荷；
3. **co-design 代理状态**：在生产空间场数据上训练的展向—弦向基系数
   `a_k(t)`；只有通过面压力、压力中心、虚功和设计域外推守卫后，才允许替代显式涡片。

### 3.2 涡粒子、涡片与空间 ROM 的方向比较

- **全涡粒子/rVPM**能表示复杂拓扑，但粒子数、近壁压力恢复、重连/扩散以及对设计变量
  的平滑导数代价高；本仓 N3.1f 的既有实现还有独立数值证伪，因此不作为当前生产主线。
- **有限翼 LEV 涡片/涡环 + UVLM**复用 N1 的面板几何、诱导速度、Kelvin 账和
  Bernoulli 压力端口，能把载荷保留在原面板上；这是 V4.1 最短且物理闭合的研究路线。
- **空间基函数 ROM**可用于大规模 co-design，但基必须来自跨质量/刚度/运动设计域的
  涡片、高保真 CFD 或实验场数据。只用 Meng 根部总力训练的 ROM 仍不可辨识。
- **从有限矩假定 Gaussian/椭圆涡核再分配**属于额外闭合假设，可做敏感性边界，
  不能作为经验证的唯一载荷模型。

因此推荐的模型不是“LEV 涡量矩状态模型”单独承担所有任务，而是
**空间涡片生产模型 + 涡量矩观测 ROM + 共轭结构映射**。当计算预算要求降阶时，
降的是空间场的坐标维数，不是删掉空间场后再按面积或刚度补摊。

### 3.3 “全翼载荷分配”的正确前向定义

“载荷分配”容易暗示从总力反演局部力，正确计算应是以下前向链：

```text
设计变量 d = {质量分布 d_m, 刚度/铺层 d_k, 几何 d_g, 运动参数 d_u}
       ↓
结构状态 q_s, qdot_s 与气动网格 x_a=g(q_s,d_g)
       ↓
LESP 起涡/供给 + 有限翼 LEV 涡片位置、强度、连接和对流
       ↓
各气动面板的诱导速度、束缚环量和非定常势跳
       ↓
Delta p_j(t), f_a,j(t)             （一级输出：面板场）
       ↓ chordwise/spanwise sums
截面六分量载荷 w(y,t)              （二级输出：梁/翼肋载荷）
       ↓ Q_s=J_as^T f_a
结构广义载荷、应变和气动功          （三级输出：结构响应）
```

一级输出决定局部压力中心和蒙皮/翼膜载荷；二级输出给出展向弯矩、扭矩和剪力；
三级输出驱动梁、壳或多体模型。三级合力正确不能反证一级分布正确，所以验证门必须
按一级 → 二级 → 三级逐层设置，不能只守根部六分量。

在第一版 co-design 中，最小充分空间分辨率不是每个流体粒子，而是：

1. 结构设计所需的展向站位；
2. 每个站位上足以移动压力中心的弦向面板；
3. 能连接相邻站位、翼尖和尾迹的 LEV/TEV 涡片拓扑。

这使有限翼 LEV 涡片 + UVLM 比单个全局涡量矩更有信息，也比全域粒子法更接近当前
计算预算。涡量矩仍从该空间场投影得到，用于总力/角冲量 guard 和快速控制，不参与
压力事后分摊。

若后续必须为大规模优化降阶，允许的替代对象是面压力场或空间涡片场：

```text
f_a(t;d) ≈ f_bar_a(d) + Phi_p(d) a(t),
```

而不是从 `F_total(t)` 构造经验权重。`Phi_p`/`a` 必须在跨 `d_m,d_k,d_g,d_u`
的训练域中建立，并逐项守恒合力、合矩、压力中心、结构虚功和气动功；否则只能作为
筛选器，不能承担最终结构设计。

## 4. ④ 有证据方案与预登记

### 4.1 D9：N5.1c 运动学身份审计（已执行）

代码定义

```text
theta = A_f sin(s)
psi   = A_t (y/span) sin(s + phi)
```

代码平翼采用 `+x` 从前缘指向后缘、`+z` 向上。正 `psi` 使后缘向 `+z`，即
nose-down/washout。论文 Figure 10 以 `tau=t/T=0` 为上止点，随后进入下扑，
正 twist 从零增加；对齐 `s=2*pi*tau+pi/2` 得

| `tau` | `theta/A_f` | `psi/A_t, +90°` | `psi/A_t, -90°` |
|---:|---:|---:|---:|
| 0.00 | +1 | 0 | 0 |
| 0.25 | 0 | -1 | +1 |
| 0.50 | -1 | 0 | 0 |
| 0.75 | 0 | +1 | -1 |
| 1.00 | +1 | 0 | 0 |

因此 Figure 10/§4.2 的实验身份在当前代码约定下唯一映射为 `-90°`。求解器只算
`y>0` 半翼，另一翼通过 `y→-y` 且反转涡环绕向作对称延拓；镜像保留截面 `x-z`
的 nose-down/washout，故不改变相位判定。Figure 14 的 body/wind 轴只改变合力
符号变换，也不改变局部旋转身份。

**D9 = GO（输入身份）**，但 **D8 = NO-GO（物理充分性）** 继续有效：`-90°`
本身仍未恢复 thrust 趋势或正确 lift 峰位。生产默认和 118 基线不得因 D9 自动修改；
必须把相位修正作为新的输入基线，重新走代表点和完整守卫。

### 4.2 D10：空间 LEV 影子状态，禁止直接加力

第一阶段只在每条带输出，不接入力：

```text
Gamma_LEV(y,t)
centroid (x_c,z_c)
second moments (M_xx,M_xz,M_zz)
surface/topology label
feed, convection and detachment fluxes
```

这些量必须来自同一个可对流的空间涡片/基函数状态；不得从目标总力反推，也不得用
`cds/Tv/crit` 调到实验曲线。

**GO 门：**

1. Kelvin/环量账和新增涡量供给逐步闭合；
2. 由空间状态产生的面板力之和与总力/总力矩账守恒，且不与 N1 束缚力双计；
3. 相同总环量但不同涡位置的规范算例能产生不同压力中心；
4. `-90°` Figure 16 工况中，twist 增大时的拓扑/压力中心变化能解释双峰衰减，
   不是靠全局归一化；
5. 面板到结构映射通过合力、合矩和虚功三重守恒。

**NO-GO 门：**

- 只在最终总力上匹配、面板压力靠面积/刚度后分配；
- 固定单涡拓扑跨越全部刚柔设计域；
- 复活 N3.1f 已封存粒子实现或用目标数据调涡力幅值；
- Meng 总力数据被误称为面压力验证。
- 设计变量通过面积、局部刚度或目标应变直接进入气动力事后分配器；
- 代理模型只守总力，不守面板压力中心、翼根弯矩、扭矩、气动功和设计域外推误差。

### 4.3 证据缺口

Meng 数据只能验总力，不能单独晋升 D10。面载荷需要新增至少一种独立证据：

- 同运动学/雷诺数的时间分辨 PIV/涡位置与环量；
- 面压力或压力敏感涂层；
- 结构表面应变/形变反演，并给出不确定度；
- 或经规范算例验证的高保真 CFD 作为空间场中间锚。

在这些证据进入树之前，V4.1 可以继续用于刚性翼总力研究，但不得宣称已能可靠优化
质量/刚度分布。
