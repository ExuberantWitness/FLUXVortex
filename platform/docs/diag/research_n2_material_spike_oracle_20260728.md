# N2.6c1b 裁决：材料面曲率变化是分离几何量，不是载荷闭合

## 0. 当前范围

本裁决只处理气动链：

```text
近壁速度场
  -> 流体材料面流映射
  -> Weingarten 映射变化
  -> 正值主曲率变化脊
  -> 分离流形。
```

它不实现结构求解、气动—结构传力或载荷标定。即使未来需要面板压力供结构
设计使用，本阶段也只回答气动上的“流体从哪里、何时开始形成分离 spike”。

## 1. 病因、数据指纹与可动空间

### 1.1 V4.1 当前状态类型不够

V4.1 的 L-B/DS 生产链以条带 `A0/f2/Tv` 为状态。它可以给出起涡事件和
均值力修正，却没有：

- 双侧近壁三维速度场；
- 具有材料身份的近壁流体面；
- 从 `t0` 到 `t` 的流映射；
- 曲面上的分离线/面拓扑。

因此 `A0/LESP` 或每条带的 `Cf=0/Hcrit` 最多是事件候选，不能给出三维
分离流形，也不能为后续空间 LEV 状态提供位置、侧别和释放边界。

### 1.2 可动与冻结空间

允许改写：

```text
N2.6b4f -> N2.6c1b -> N2.6c1c -> N2.6c2c。
```

禁止：

- 修改 N1、N4 或其他 validated/frozen 节点；
- 把 `N3.1f` 旧粒子力支路重新命名后复活；
- 用 L/T、压力残差、LESP 或结构响应选择材料时间窗、脊阈值或分离位置；
- 把制造几何称为动态失速验证。

## 2. 学科机理：一手文献中的精确定义

Santhosh et al., JFM 969 (2023) A25 的定义可拆为四层。

### 2.1 对象是流体材料面，不是翼面几何

初始近壁材料面为

```text
M(t0) = {r(u,v)}，
M(t)  = F_t0^t(M(t0))。
```

同一个 `(u,v)` 在两个时刻必须标记同一批流体粒子。翼面自身的曲率、两个
无材料对应关系的 Eulerian 等值面，均不满足该定义。

### 2.2 曲率由第一、第二基本形式共同确定

论文 Eq. (3.3)：

```text
W(t) = Gamma1(t)^(-1) Gamma2(t)。
```

`W` 是材料面的 Weingarten 映射，其两个实特征值是主曲率。仅对坐标分量
做二阶差分、忽略曲面度量，不是同一个量。

### 2.3 分离指标是有限时间曲率变化

论文 Eq. (4.1) 定义：

```text
Wbar(t0,t) = W(t) - W(t0)。
```

其最大特征值 `kappa_bar_2` 表示流映射诱导的最大正向折叠。生产对象不是
最终 `W(t)`，更不是翼面静态曲率。论文 Proposition 1 还要求该量对材料面
重参数化及任意时变 proper Euclidean 观察者变换保持不变。

### 2.4 高曲率值仍不等于分离骨架

Definition 1 / Proposition 2 对骨架增加了拓扑条件：

- 一维骨架：每个近壁材料层上 `kappa_bar_2>0` 的局部极大点；
- 二维骨架：`kappa_bar_2>0`，沿最大主方向一阶导数为零、二阶方向导数
  为负的 wall-transverse ridge；
- on-wall spiking point/curve 是骨架与无滑移壁面的交集；
- 后续骨架位置仍须由同一流映射推进。

所以“取最大的几个网格点”或增加任意幅值阈值都不是文献定义。

## 3. 缺组件还是组件错误

### 3.1 错组件

以下生产替代均 **NO-GO**：

1. `Cf=0` 或固定 `Hcrit` 直接作为分离流形；
2. `A0/LESP/BEF` 同时充当触发、持续供给幅值和空间分离边界；
3. 只计算最终材料面的曲率 `W(t)`；
4. 计算翼面自身曲率，并将结构运动误判为流体脱离；
5. 从总力误差选择积分时间窗或 ridge threshold。

### 3.2 缺组件

`N2.6c1b` 至少缺三项可独立证伪的组件：

1. **几何身份**：由同一材料网格的两个时刻计算 `Wbar` 和主曲率变化；
2. **场驱动流映射**：从独立近壁三维时序速度场客观推进一族流体材料面；
3. **骨架提取**：按正值、stationarity 和负二阶方向导数条件提取 1D/2D
   脊，并证明网格、法向层间距及 `[t0,t]` 时间窗收敛。

只有第 1 项目前具备不依赖物理场的制造解验证条件。

## 4. 针对机理的树改写

### N2.6c1b1：材料面 Weingarten 变化身份

新增 `material_spike_geometry.py`，输入只含同一流体材料面的初末位置、材料
坐标和时间：

```text
{r(t0), r(t), u, v}
  -> {Gamma1, Gamma2, W(t0), W(t), Wbar,
      kappa_bar_1, kappa_bar_2}。
```

预登记在 `material_spike_geometry_cases.yaml`。结果：

- 平面最大曲率误差：`0`;
- 圆柱细网格最大误差：`1.2835e-4`，相对粗网格比：`0.06260`;
- 静态材料面 `max|Wbar|=0`;
- 抛物折叠原点最大主曲率变化误差：`4.44e-16`;
- 初末时刻采用不同 proper rotation/translation 时，最大客观性残差：
  `8.80e-13`;
- 线性材料坐标重参数化残差：`2.49e-13`;
- improper observer 变换被拒绝。

因此只将 **几何身份** 晋升为 validated/frozen。

### N2.6c1b2：独立场驱动的材料面流映射

保持 open。它必须消费通过 `N2.6b4f3` 契约并在 `N2.6b4f3b` 取得的合格
近壁时序场，推进多层、双侧材料面，并验证无滑移邻域、积分器阶数、时间
反演/步长误差和观察者客观性。`N2.6b4f3a` 已对六项公开资产完成联合资格
审计：Cambridge/Edinburgh 虽有连续二维速度场，但没有合格壁面/edge 身份
且 Re 不符；Zenodo 只发布平均场和孤立 `tau` 快照；Glasgow 只有压力；
KTH 是静态剖面。没有资产可使本节点晋升。

为避免把“缺数据”与“数值算法未定义”混成一个命题，b2 再拆为：

- `N2.6c1b2a`：给定解析速度场的无载荷 flow-map 数值身份；
- `N2.6c1b2b`：合格独立场的时空插值和目标域材料面推进。

`near_wall_material_flow_map_cases.yaml` 在实现前冻结 b2a 的平移、旋转、
时变观察者和无滑移非线性折叠门。结果为：

- 刚体旋转步长减半误差比分别为 `15.98`、`16.00`，符合 RK4；
- 时变观察者轨迹最大误差 `1.09e-12`;
- 解析无滑移折叠的位置误差 `2.91e-14`，壁面层运动误差为 `0`;
- 将积分结果送入 b1 后，最大主曲率变化误差 `3.84e-12`。

因此 b2a 可 validated/frozen；b2b 因没有合格独立场仍为 open，b2 父命题也
保持 open。该积分器与 DDE 自诱导涡片推进分离，不能以旧 wake-sheet 测试
替代近壁流体场证据。

### N2.6c1b3：正值主曲率变化脊

保持 open。只有 b2 输出的场级 `kappa_bar_2(u,v,eta)` 才能用于提取
Definition 1 的一维/二维 backbone。制造抛物面只能测试算法身份，不能证明
它找到真实分离。

这里继续拆分“局部微分条件”和“连通场级骨架”：

- `N2.6c1b3a`：单层网格上的正值、stationarity、负定 Hessian/负二阶
  方向导数；
- `N2.6c1b3b`：跨网格与法向层的连通 backbone、壁面交线和独立场验证。

`material_backbone_conditions_cases.yaml` 预登记制造场后，b3a 得到：

- 二维 Gaussian ridge 的 41 个预期节点全部命中，旁支为 0；
- 各向同性 Gaussian 最大值只产生 1 个一维候选；
- 负值 downwelling 最大点和方向最小点均被拒绝；
- 网格加密的导数误差比分别为 `3.95`、`3.99`，符合二阶差分；
- 线性材料坐标重参数化的候选 mask 差异为 0。

因此 b3a 作为“微分条件身份” validated/frozen。b3b 仍 open，因为候选 mask
尚未形成多层连通材料骨架，也没有真实 spiking point/curve 对照。所有
stationarity、负曲率和特征值 gap 容差均为显式数值误差带，禁止从总力或
最佳分离位置反选。

## 5. Go / No-Go

### GO

- 用 b1 作为后续流映射和 ridge 代码的几何 oracle；
- 对独立场数据预登记材料层、时间窗和网格收敛；
- 让 `N2.6c1c` 的低阶近似对 b2+b3 场级位置/时间误差负责。

### NO-GO

- 当前宣布 `N2.6c1` 或 V4.1 分离闭合完成；
- 把 b1 接进生产载荷链并据三点/118 总力选择参数；
- 在没有 b2 场证据时实现任意 threshold ridge；
- 将该模块输入替换成翼面结构几何。
