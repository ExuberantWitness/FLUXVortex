## ② 学科机理 — 开放式文献扩展（一手锚）

### 候选 C 死因辨析（关键窗口）
已证伪的候选 C sep_drag 是 **f² 型**（∝V_local²·sin²(α_rel)，局部速度含扑动速度 ḣ → 周期均值 ∝f²）
→ dT/df 形状破坏（Pearson 0.995→−0.03）。**我的指纹是 f 无关**——这打开了一个 Codex
未探索的窗口：**准定常分离压差阻（∝U² 自由流标度）与 f² 型有本质区别**。

### 一手文献锚定

1. **DeLaurier, *Aeronautical J.* 97 (1993)**（memory ㉑ 已验）：
   分离流态下 chordwise 力全零（T_s=D_c=D_f=0），正常力 = **cross-flow drag**：
   ```
   (dN_c)_sep = (C_d)_cf · (ρ·V_r/2) · c · dy,   V_r = √(V_x²+V_y²) 中弦法向合速度
   (C_d)_cf = 1.98  (高展弦比平板法向阻系数, Larijani & DeLaurier 同)
   ```
   分离态附加质量减半：N_a,sep = N_a/2。

2. **Pomerenk & Ristroph, arXiv:2508.19899 (2025)**（准定常扑翼推进，一手）：
   分离阻 **C_D^S(α) = C_D^(π/2)(Re)·sin²α**，C_D^(π/2)≈1.8（高 Re 平板法向阻），
   与 DeLaurier 的 1.98 同量级。**周期均值视角 f 无关**——与我的指纹直接匹配。

3. **改进准定常动物飞行模型, arXiv:2302.09602 (2023)**：
   实测 C_D(α) 可用纯三角函数（sin²α 形式）精确建模——分离阻系数的标准性佐证。
