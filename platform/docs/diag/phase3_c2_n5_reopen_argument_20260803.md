   属 N3.1 内部口径问题，但 N3.1 修正路径已全部证伪（B1/B2/G + direction_tests）。
3. **L(twist) 反号 = 结构不可达**（双登记：N3.1 形状不可达 + N5 相位不可用），
   维持战役 2 结论。L 通道残差（trend 0.238）为可接受残差，除非出现：

   相位 −90 + 补推力 可重新评估——但那是组合战役，禁并行，需分别预登记）。
