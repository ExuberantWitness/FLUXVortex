## 0. 案情

生产常数 `a0_crit=0.27`(SD7003@Re2e4 区间上端取值)同时把守**两个通道**:
① LEV 脱落起始门(LESP=A0 越界即剪切);② 吸力饱和帽(les_sep='plateau' 下
c_s 钉在 2π·a0_crit²)。它是从文献区间 0.12–0.27 里**手挑**的,对薄弯度膜翼+
Ø8mm 圆杆前缘(r/c=4/287≈1.39%)、Re≈1.5e5 无独立论证——co-design 跨翼型时
彻底失效。需要:LESP_crit(前缘半径, 厚度, 弯度, Re) 的发表律/可计算判据。

**裁定基调**:文献**没有**现成的 LESP_crit(r/c, t/c, camber, Re) 闭式表——K4 作者组
的结论恰恰是"固定常数不可扩展,应换可计算判据"。因此 co-design 答案是
**分层**:通用可计算流程(Tier 1/2)+ 快速筛选闭式(Tier 3,自 K1+K3 组装,标注外推)。

## 2. VERDICT:co-design-ready 配方(三层)

### Tier 1(首选,任意翼型通用流程):BL-criticality 可计算判据(K4)
对每个候选截面+Re **离线**求 LESP_crit:在 2D LDVM/薄翼势流速度分布上耦合
非定常积分边界层,做一次标准俯仰 ramp,边界层临界性(K4 判据)触发瞬间读出
LESP → 即该 (截面, Re) 的 LESP_crit;由 K2(运动学无关性)一次求值全运动域适用,
建表 `LESP_crit(section, Re)` 进 co-design 缓存。
**常数**:无自由常数(判据内常数属 K4 发表方法)。**适用域**:Re 1e4–2e5、
前缘起始 LEV 主导 regime(K4 验证范围);膜翼圆杆前缘属几何外推,须标注。

### Tier 2(后备):单次黏性 ramp 标定(K2+K6)
每 (截面, Re) 跑一次 2D 黏性 CFD 俯仰 ramp,用 K6 的 Cf 拐点判据判 LEV 起始,
读该时刻 LESP。K2 保证一次运行足够(跨运动预测)。**零拟合合规**:标定对象是
截面物理,不是我们的测力数据。成本 ~1 CFD run/截面,co-design 内可接受。

### Tier 3(快速筛选闭式,本翼型即用值):√(r/c) 标度 + 文献锚
K3 给出前缘速度 ∝ A0/√(r_LE):若取"临界前缘速度比"为截面族内近似不变量,则

```
LESP_crit(r/c) = 0.14 · sqrt( (r/c) / 0.0085 )        [锚:SD7003@Re=1e5, K1]
```

- (r/c)_SD7003 ≈ 0.0085 由坐标密切圆拟合(实现时须用 UIUC 坐标复核,此值为估计)。
- 我们的截面:r/c = 4/287 = 0.01394 → **LESP_crit ≈ 0.18**。
- Re 修正:K1 给 SD7003 幂律 (Re/1e5)^(−0.176)(1e4–1e5 内拟合),1.5e5 处 ×0.93→0.17;
  但 K5 在低速率区给出**反向** Re 趋势——方向有争议,**不进点值,进带宽**。
- **敏感带(prescription)**:`a0_crit ∈ {0.14, 0.18, 0.22}` 三点扫。
  下界 0.14 = 拒绝几何信用的纯文献锚(K1);上界 0.22 ≈ 文献记录最大值 0.21(K1)
  + K4"更圆更高" + K7 速率信用方向;**0.27 高于全部文献记录值,退役**。
  co-design 输出报告力的**带**(band),不报点值。

## 3. 实现配方(单变量纪律,防双计)

1. **S1(本报告主变量)**:`a0_crit: 0.27 → lesp_crit(r_c=0.01394, Re=1.5e5) = 0.18`,
   以函数+日志替代硬编码;其余全部冻结(les_sep='plateau'、lev_place='ansari'、
   lev_rollh=0.5、attached_drag='faure' 一律不动——它们是 track 2 的变量)。
   注意 a0_crit 是**一个常数管两个通道**(脱落门+饱和帽 2π·a0_crit²),同改是语义
   自洽而非双计;帽值 0.27→0.18 即 0.457→0.203,**帽掉 2.25×**,高载荷工况响应会很大。
2. **S2**:同一提交内加诊断输出:逐工况超临界占空比(duty cycle)与 T_les 分量
   vs a0_crit∈{0.14,0.18,0.22}——先看占空比响应再看力。
3. **S3(敏感带扫描)**:三点扫过全 118 工况,产出带宽表;若 0.18 使 U8/tw22.5
   gapT 斜率门(见 §5)回退而 0.22 守住,即为 K5/K7 速率信用的经验支持——取上带,
   **不许**向测力数据回归拟合。
4. **S4(co-design 通道)**:实现 Tier 1 离线评估器(LDVM+IBL ramp harness),
   对任意候选截面吐 LESP_crit 表;Tier 3 闭式仅作 co-design 内层循环的快速筛,
   进入外层验证前必须用 Tier 1/2 复算。
5. **双计红线**:(a) 若任何分支重新启用 K_T split(kt),K_T 已封吸力,再叠
   a0_crit 帽 = 双帽,禁止叠加扫描;(b) a0_crit 变小 → 剪切涡量变强 → LEV 升力
   通道(Bernoulli v_L + ∂Γ_L/∂t)自动响应,**不得**再动 lev_vnf/涡升力系数补偿。

## 5. 验证门(118 工况 sweep)

**最敏感曲线(必须改善或给出带宽解释)**——按超临界占空比排序:
1. **U8/tw22.5 频率线(aoa0/5/10)**:T_les 直接受门控;守 gap_t1 验收门
   `|gapT 斜率| < 0.3 N/Hz`(plateau@0.27 反事实已给 +1.30 vs 需求 +1.44,
   帽降低后此门是第一个可能回退的——三点带扫裁决)。
2. **扭转深端(tw≥30)@2.6Hz:U8/aoa15(gap 律 R²=0.69)与 U10/aoa5(R²=0.72)**:
   实测净推力在标称 tw30 之外快速恶化而模型过平——帽 ∝ a0_crit² 是模型在此处
   "响应过钝"的第一嫌疑变量,深扭转尾段**必须**出现向实测的弯折。
3. **f@tw0 纯挥拍线(U6/aoa5 斜率 0.577、U8/aoa15 斜率 0.847、U10/aoa5 0.786)**:
   吸力是纯挥拍推力主源,a0_crit 定超临界占空比;U6 vs U10 对照兼验 Re/k 趋势方向。

**不许回退(no-regress 门)**:
- tw0 巡航锚点双通道 |Δ|<0.15 N(gap_t1 记账原则);
- 低频低攻角亚临界点(tw0, f≤1.7, aoa≤5):全程门下,应**不变**(|Δ|<0.05 N)——
  若移动即暴露双计或门语义泄漏;
- 全局曲线均值 MAE:推力 ≤0.84 N、升力 ≤0.87 N 的现状不回退(升力硬上限 1.2 N);
- 升力通道整体:a0_crit 变小会增强 LEV 剪切与涡升力路径,盯 U8/aoa0 与 aoa15
  的 tw 扫升力行(现 R²=0.75/0.35 的 tw² 结构)不得恶化。

## 6. 文献不支持或存疑的部分(明确列出)

1. **不存在发表的 LESP_crit(r/c, t/c, camber, Re) 闭式全律。** Tier 3 是我们用
   K1+K3 自行组装的筛选式,不是任何单篇文献的结论;进论文/对外结论须走 Tier 1/2。
2. **Re 趋势方向未决**:K1(SD7003 随 Re 降)vs K5(低速率区随 Re 变化、分段线性
   速率依赖)。恒常数假设本身在低速率区受挑战——只能敏感带兜底,不能文献定点。
3. **K7 速率信用是 k=0.1 的外推**,我们 k=0.25–0.45;方向可信,定量无锚。
4. **圆杆+膜前缘 ≈ 光滑翼型密切圆**是本报告最强的几何外推;K4 只给方向
   (更圆→更高),无定量;若 Tier 2 CFD 可行,优先对本截面跑一次 ramp 直接定值。
5. **弯度效应无幸存定量条目**;2% 弯度靠"与 SD7003 1.45% 接近"吃锚,属未建模项。
6. **帽语义(plateau vs 黏性塌缩)是 track 2 的未决案**(Katz-1981 假设 vs
   Narsipur-2020 塌缩,两派文献并存;v2 口径下 plateau 赢了反事实但深扭转过平)——
   本报告刻意不动它;若 track 2 换语义,a0_crit 的帽通道含义随之变,带扫须重跑。
7. **Ramesh 2014 原文闭源**,数值经 Faure 2019 / Gelado & Ramesh 2022 / UNSflow
   源码三路间接核实,原表未直接目验。

**一句话决策**:a0_crit=0.27 退役;本截面取 **0.18**(= 0.14 锚 × √(r/c) 几何信用),
敏感带 {0.14, 0.18, 0.22} 三点扫报带;co-design 通用解 = Ramanathan-2023
BL-criticality(或单次 CFD ramp + Cf 拐点)离线建表,闭式仅作内层快筛;
裁决门 = U8/tw22.5 斜率不回退 + 深扭转尾段出现弯折 + 亚临界点纹丝不动。
