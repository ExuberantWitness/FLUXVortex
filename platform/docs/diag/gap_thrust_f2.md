## 3. 代码级归因(嫌疑通道锁定)

K0 与 H16 生产 preset 均含 `les_suction=True, les_eta=1.0`(_v2_repro_nc12.py:16)。

```
dTs = π · les_eta · ρ · c_le · dy_le · Vle_m² · sa_s²      (Garrick/Ramesh LE 吸力)
sa_s = clip(A0, −a0_crit, +a0_crit)                        (LESP 饱和,a0_crit=0.23/0.27)
```

代码注释自证(_v2_robo.py:1104-1106):"A0 caps at sin(alpha_crit) (LESP), but the **LOCAL
dynamic pressure ~Vle_m² still grows with flap speed → F_A ~ f² even when saturated.
This is the f² propulsion.**"——模型自身的 f² 推力**全部**由该通道产生
(vnf 的纵向投影当年测得 ≈0,_v2_robo.py:1208-1210)。历史量级:tw45 时 les 通道 +19.4N。

### 3.1 手算量级(饱和态上界)

饱和态 f² 系数:b_les = π·ρ·a0_crit²·Σ(c_j·dy_j·y_j²)·½(2πΦ)²,Φ=0.785 rad(±45°):
≈ 0.2036·0.0376·12.16 ≈ **0.093 N/Hz²/半翼 → ×2 ≈ 0.19 N/Hz²**(整机)。
≈ 观测 GAP 斜率(0.40)的一半 → **另一半来自缺失的真实阻力**(见 3.2)。

### 3.2 缺失阻力候选:瞬时相对速度上的剖面阻力

逐段阻力沿局部 V_rel=(U, v_flap) 方向,其纵向分量 ≈ ½ρ·c·Cd·U·V_rel
≈ ½ρ·c·Cd·(U² + v_flap²/2),周期平均给出 **c(U)∝U² 偏置 + b·f² 项,b 与 U 无关**——
与 GAP 律三特征中的 (a) 完全一致。b_drag = ⅛ρ·Cd·(2πΦ)²·∫c·y²dy·2 ≈ 0.28·Cd N/Hz²;
b_drag≈0.2 需 Cd≈0.7(中冲程外段瞬时 α_eff 30–50°,深失速区 Cd 量级合理,需文献 polar 锚定)。
⚠ H20 教训:平板 CN(cd_form=1.98)直接叠加过粗——本次必须用文献 Cd(α) polar + 只作用于
纵向分量,不动法向力平衡(升力已达标,不许破坏)。

## 4. 文献裁定(step-2,已完成;全文 research_les_suction.md,18/18 题录对抗核实通过)

**主犯(4 条独立 CONFIRMED 证据链):"超临界期间吸力保持在临界值"的 LDVM 假设是错的。**
- 我们继承的是 Ramesh 2014 (JFM 751) 的处理:超临界时 A0 钉在 ±LESP_crit,吸力平台
  2π·LESP_crit² 全程激活(UNSflow 源码逐行核实 + Faure 2019 独立复现)。
- 该假设被 Hirato 博士论文明确标注为**未经证明**(溯源 Katz 1981 的 "proposed flow behavior")。
- 黏性真相:**Narsipur et al. 2020 (JFM 900, A25;LDVM 原作者组自己的修正)**:黏性 LESP 在
  前缘分离时**跌至近零**,与 LEV 是否形成无关(Re 1e4–1e5,覆盖我们的 1.2e5)。
- 佐证:Deparday 2022 (JFM 941) PIV 直接测量;Mackowski & Williamson 2015 (JFM 765) 直接
  测力证明 Garrick 大频率下显著高估平均推力。

**从犯:亚临界段 η_s=1 也偏高。** 零拟合可行路线 = Carlson NASA TP-1500 attainable-thrust
因子 K_T(闭式,输入仅 t/c≈0.028、r/c≈0.014、Re=1.2e5)。DeLaurier 1983/1993 谱系一贯
η_s<1,但具体数值无文献锚(0.98 坊传未获核实)——不能直接取值,必须走 K_T 闭式。

**加重情节:a0_crit=0.27 高于全部文献记录。** SD7003@Re=1e5 的 LESP_crit=**0.14**
(Ramesh 验证集,随 Re 上升而降);0.27 无出处(Ramanathan 2023 方向上支持钝前缘更高,
无定量)。需以 0.14 做敏感性对照。

**机理 C(瞬时速度剖面阻力)裁定为非 f² 来源**——但注意两点诚实披露:①该角度检索
agent 失败(4/5 角度回传),②综合的驳斥论证有瑕疵(周期平均后 ½ρcCd(U²+v²/2) 的 f²
项系数其实与 U 无关)。真正的裁决来自归因诊断(§3.3):模型 f² 斜率 95% 在 les 通道,
**先杀吸力虚构,修后残余 GAP 再决定是否需要补真实阻力**(它最多贡献 c(U) 与小残余 b)。

**推荐实现**(全部有文献出处、零自由参数):
1. 超临界期间弦向吸力不再保持平台:**3a 置零**(Narsipur "near-zero")或 **3b Polhamus
   旋转**(吸力大小保留、转为法向涡升力,弦向推力自动归零;NASA TN D-3767/J.Aircraft 1971)。
   3b 对法向力更保真(建议主实现),3a 作消融。注意:LDVM 家族无 3b 先例(自主偏离);
   Hirato p.94 警告深失速初始 LEV 生长期封顶反而低估吸力。
2. 亚临界段乘 Carlson K_T(TP-1500 闭式)。
3. LESP_crit=0.14 对照扫描。

**验证预测**:f² 系数塌至 ≈0,tw0 翻号为净阻力(−0.5..−3N 量级);残余退化为纯 c(U) 型
且不随扭转增长;升力经 sinα 小项受扰,预期个位数百分比(必须复跑确认);若 f² 只降一半
→ 亚临界份额(K_T)被低估。
