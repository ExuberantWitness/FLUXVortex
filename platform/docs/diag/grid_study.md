## 3. 布点律(加密方式,本研究核心判定)

弦向余弦布点(生产现状)TE/LE 面板 ∝ c·(π/2nc)²(**二次坍缩**:nc8 11mm →
nc16 2.75mm);均匀布点 ∝ c/nc(线性)。

```
扑动 bern     nc8     nc12    nc16     静态 nc16
cosine       13.91 → 11.02 → 8.50     16.92
uniform      13.90 → 13.42 → 13.56 ✓  17.55
uniform L_wind 15.48 → 14.80 → 14.99;实测 15.14 → 最恶劣角点 gap −0.15N
```

**判定:发散 = 余弦 TE 二次坍缩 × 近尾迹奇异采样的相互作用。**机理:非定常下
相邻尾迹环 ΔΓ~dΓ/dt·dt 不再对消,TE 行配置点(距 TE 丝 0.25×TE 面板)随 nc
二次坍向携带净环量的近奇异丝;静态 ΔΓ=0 全对消 → 免疫。cosine nc4/nc8 时代
距离尚大(10/2.7mm),nc12+ 进入病态区——**生产 nc12 cosine 的 28 点升力
"亏空"大部为此伪影**。

## 4. 失败的替代修复(tev_core,归档为反面教材)

"给老 TEV 行加解算液核"三版全灭(gap_lift.md §2.8):
- v1(核=0.4×四边平均):静态 16.92→3.66(展向长边把核撑到片宏观场尺度);
- v2(核=κ×流向间距,米值):静态→4.23;A/A(核=底值 0.0014)f32/f64 双路由
  同塌 4.84 → 破案:kernel δ 为**无量纲**(等效核=δ×段长),0.0014 底值在余弦
  nc16 的 0.7mm TE 距离上砍掉贴附行 TE 丝 80% 诱导,Kutta 崩塌;
- v3(新行 δ=1e-4 + 老行 δ=κ×流向/展向比):A/A 回归过(17.58),但 κ=1 静态
  再塌 5.19。**结论:亚厘米距离的近尾迹诱导是物理承载的(束缚-镜像-启动涡回流),
  解算内正则化近尾迹 = 死路。**参数保留仅作诊断。
