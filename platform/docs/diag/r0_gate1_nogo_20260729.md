## 裁决

按原始 go/no-go 文义，本次必须记为 **NO-GO**，不得晋升 R0。

失败只发生在“跨进程历史 anchor 必须逐 bit 相同”这一控制条件。既有两次
历史 anchor 本身也不相同，说明该条件没有先建立 bitwise control
reproducibility；因此它不能辨识运行后账本改动是否改变气动输出。probe
恰好逐 bit 相同不能覆盖两个失败的 anchor。

下一步不得放宽后宣称本次通过。必须先独立预登记一个可辨识的新控制：
在每次 solver 调用内部、ClaimGraph 执行前冻结旧 API 气动力字段的二进制值，
图执行后逐字段验证完全不变；跨进程 anchor 继续使用已有 `0.15 N` 正式
复现门。新门通过前 R0 保持 `partial/unfrozen`。
