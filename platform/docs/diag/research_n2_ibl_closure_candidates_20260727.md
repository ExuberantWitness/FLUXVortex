# N2.6b4 闭合候选裁决：持续 LEV 供给不能停在准稳态三方程 IBL

## 1. 数据域指纹

RoboEagle 根部弦长约 0.287 m，来流 6–10 m/s；仅以自由来流估算，
弦长 Reynolds 数已经在约 \(1.1\times10^5\)–\(1.9\times10^5\)，扑动局部
相对速度还会扩大范围。模型必须面对：

- 层流—转捩—湍流状态切换；
- 强非定常逆压梯度和首次回流；
- 旋转/扭转诱导横流；
- 分离之后由 DDE 接管的自由剪切层。

因此闭合证据必须覆盖“首次回流之前”和“分离释放边界”，不能拿定常附着翼
或纯层流二维起涡结果代替。

## 2. 四类候选

### A. Ramanathan–Gopalarathnam 准稳态二维 IBL

**角色 GO：起涡事件的独立基线。生产持续供给 NO-GO。**

该工作用非定常面板压力驱动每时刻的准稳态 IBL，以边界层临界性预测首次
前缘回流。作者明确限定于 LEV 形成前的附着流，并指出稳态 IBL 不能预测首次
回流之后的边界层发展；其主要验证域是低 Reynolds 数层流二维俯仰。

所以它支持“LESP 不是持续幅值、边界层状态应决定起涡事件”，不支持三维
横流输运、转捩后分离或 DDE 连续供给。

### B. ONERA 三方程张量 IBL + 简化剖面

**方程骨架 GO；现有生产闭合 NO-GO。**

其 \(\mathbf M/{\rm tr}\mathbf T\) 守恒形式适合任意曲面有限体积，已经成为
`N2.6b3` 的方程骨架。但论文的首版湍流剖面明确忽略横流，并明确不能表示
湍流边界层分离；弱黏性—无黏耦合也不处理三维强相互作用。这个闭合可作为
附着/弱横流回归基线，不能承担 RoboEagle 生产方向。

### C. Drela IBL3：四方程剖面 + 两方程应力/转捩输运

**生产参考架构 GO，具体闭合仍待本项目验证。**

IBL3 用四个方程表示分离和 crossover 剖面，再以两个附加方程输运 Reynolds
应力以捕获湍流滞后；层流区的应力输运退化为不稳定波包络增长，使转捩成为
状态演化的一部分。全部方程具有旋转不变形式，并与外流强耦合。

这与 RoboEagle 所需的横流、非平衡记忆和转捩层级一致。但公开验证主要面向
常规三维边界层，不能直接证明在大幅扑翼与动态失速下的闭合精度。FLUXV
只能继承其**状态拓扑和守恒结构**，不能未经场级验证照搬系数。

### D. Zhang et al. 物理约束场级回归闭合

**条件 GO：闭合研究工具；默认生产暂 NO-GO。**

该路线从高保真三维边界层解学习闭合函数，做稀疏输入选择，并在函数表示中
精确嵌入横流对称性；湍流应力输运由模型反演校准。它说明数据驱动可以作用于
不可解析的剖面闭合，而不必拟合总力。

对 FLUXV 的许可边界是：

- 训练目标只能是 \(\mathbf T,\mathbf E,D,\boldsymbol\tau_w\)、横流剖面和
  转捩等场量；
- 必须保留守恒方程、旋转/镜像对称、二维极限和量纲结构；
- 必须报告分布外不确定性，并由独立运动学/雷诺数/扭转工况验证；
- 不能把 L/T、面板压力残差或实验总力作为闭合标签。

## 3. 方向结论

生产状态树采用两层：

1. **必选核心**：`N2.6b3` 的三方程精确守恒块；
2. **可升级闭合块**：以 IBL3 的四加二状态拓扑为上限，按证据逐项加入
   crossover 剖面、横流应力、非平衡湍流滞后和转捩包络。

不是一开始复制六方程全部常数，而是做受控嵌套比较：

```text
C0: 三方程守恒 + 准稳态剖面（仅基线）
C1: + crossover/横流剖面状态
C2: + 湍流应力大小与方向滞后
C3: + 转捩包络/间歇性
```

每一级只在新增场量通过独立验证后晋升。首次回流之后，IBL 只推进到由壁面
剪切拓扑定义的分离流形；自由剪切层由 N2.6c 守恒释放至 DDE，不强迫 IBL
穿越大尺度分离区。

## 4. 预登记数据门

### 方程/数值门

- 刚体旋转客观、二维退化、内部通量抵消和网格收敛；
- 与 N1 外流的位移厚度/法向质量亏损在同一隐式残差中收敛；
- 转捩界面移动时不得出现随网格振荡的守恒量。

### 场级门

- 二维：\(H_{12},H_{32},\theta,C_f\)、首次回流位置/时刻；
- 三维：横流角、两切向壁面剪切、动量亏损张量和分离线；
- 非定常：应力方向/大小的相位滞后和循环间记忆；
- 分离接口：穿过分离流形的环量、质量和动量通量。

至少使用一组未参与闭合选择的 PIV/CFD/VPM 场数据。总 L/T 只在空间状态与
统一压力通过后作为积分后验门。
