四条结构性判读:

1. **纯 AoA 项归零**(+0.021 N/deg ≈ 0;逐 f 斜率外推 f=0 得 +0.021):静态/准定常
   升力线斜率**基本正确**,亏空不是升力线斜率错。缺的是随扑动出现的非定常机理。
2. **主项 = f×α 交叉项**(−0.071 N/deg/Hz):AoA 斜率随 f 线性增陡
   (f1.4: −0.087 → f2.6: −0.183 N/deg)。
3. **纯 f 项**(−0.52 N/Hz):AoA=0 时也有随 f 增长的亏空(−0.95→−1.21N,f1.4→2.6),
   AoA0 相对亏空 ~35%(实测 2.9N vs 模型 1.7N)——AoA0 时上下冲程对称性仅由拱度打破,
   指向拱度相关的周期平均升力缺失。
4. **扭转缓解亏空**(律3:+0.031 N/deg @f2.3、+0.041 @f2.6):扭转降低外侧有效攻角
   → 亏空变小。与"有效攻角越高丢得越多"一致。

## 2. 机理嫌疑(待文献裁定,按指纹匹配度排序)

- **嫌疑一:准定常几何失速砍多了(动态失速延迟缺失)。** geo_stall_vec 按几何桨距
  攻角的 Kirchhoff 因子缩放 Bernoulli 力矢量,是**准定常**判据;非定常经典结论是失速
  攻角随折合频率上移(Kramer 效应,α_dyn ≈ α_ss + γ·k̇ 类),扑动中瞬时有效攻角超静态
  阈值时真实翼(LEV 附着)不丢升力而模型丢。指纹匹配:f×α 交叉主项 ✓(f 越高扑动附加
  攻角越大、超阈值越深)、f→0 归零 ✓、扭转缓解 ✓(降低外侧有效攻角)。
- **嫌疑二:下冲程 LEV 升力增强缺失。** les_sep='kt' 把 (1−K_T) 份额转到法向,但 LEV
  的周期平均升力增强(Dickinson/Ellington 谱系,平均攻角非零时上下冲程不对称)可能
  仍未入账。与嫌疑一部分重叠(都是"高有效攻角相位的法向力保持")。
- **嫌疑三:膜拱度自适应不足。** 结构参考面平铺 + NACA2406 固定拱度偏置;真实膜在
  载荷下鼓起增拱(Song/Rojratsirikul 膜翼文献:CL 斜率增大+失速延迟)。可解释纯 f 项
  (AoA0 亏空随 f 增)与 U 强依赖(动压标度)。但 f→0 外推 AoA 斜率归零对"CL 斜率
  增大"不利——静态斜率没错,削弱本嫌疑的主项地位。

## 2.5 代码级归因(2026-07-12)

- **主嫌疑通道 = `stall` 饱和块**(_v2_robo.py:1095-1099):`sf = min(1, sin(11°)/|sin α_eff|)`
  逐面元缩放 Bernoulli 力,α_eff 取自 Vcol(**含扑动速度**)——f 越高扑动附加攻角越大、
  截断越狠;瞬时判据,**无滞后、无折合频率依赖**。tw0 家族(f×α 主项)只有它点火。
- `geo_stall_vec`(:1110-1129)用几何桨距角 |aoa+ψ_t|,tw0 时仅静态 AoA 进入;对 AoA15
  会常开(15°>12°),但产出 f 无关的纯 AoA 项——拟合显示纯 AoA 项≈0,说明其静态份额
  与实测静态失速大体相抵,非主案。
- **GK 滞后机制已存在但未覆盖本通道**:`fsep_lag`(:1011-1025, :1072-1080)只作用于
  前缘吸力分离态 fsep_le/fsep_cn;`stall` 饱和因子 sf 与 geo_stall 的 fsep 均为瞬时值。
  若文献裁定"动态失速延迟/分离滞后"成立,最小单变量实现 = 对 sf(或其等效分离态)
  挂同款 GK 一阶滞后(τ 常数取文献值,零拟合)。
