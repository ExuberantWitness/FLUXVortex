# N2.6b/c 方向裁决：曲面涡量库存，而非总力闭合或生产级全黏性粒子云

## 1. 病因指纹与树节点

已证伪的 `N3.1j4b3/b4` 表明：把 LESP 临界值逐条带反演成整张连续 LEV
片的幅值，即使改变自由边界拓扑，也不产生网格收敛的源强。`N3.1j3b1/b2`
又表明：N1/DDE 已能无歧义地提供统一压力跳、双侧势极限及移动壁面源项的
公式接口。剩余缺口不是一个 LEV 力系数，而是 N2.6b 的附着涡量库存和
N2.6c 的分离释放。

可动空间严格限于 N2.6/N3 开放节点。N1 AIC、运动学、网格和 N4 力簿记不动。

## 2. 学科机理

Terrington、Hourigan 与 Thompson（JFM 936 A44, 2022）区分了三件事：

1. 移动壁面相对无黏加速度生成界面环量；
2. 黏性把环量从界面转移到流体内部；
3. 三维涡线输运、拉伸/倾斜及法向涡量必须满足广义无散条件。

Gehlert 与 Babinsky（JFM 915 A50, 2021）的实验进一步显示，边界层涡片历史
同时受平移、旋转、局部和远场涡量影响；分离点的原始涡片强度没有普适阈值。

Koumoutsakos、Leonard 与 Pépin（JCP 113, 1994）以及 Eldredge（JCP 221,
2007）说明，黏性涡粒子法可以通过壁面涡量通量/消除滑移来求解完整
Navier–Stokes 边界层。Zhang 与 Eldredge（IJNMF, 2008,
doi:10.1002/fld.1867）把该路线扩展到连续变形的二维物体。这些工作证明
“壁面生成—黏性扩散—自由涡量”可以闭合，也同时显示它本质上是高保真
黏性求解器，而不是低成本三维扑翼生产闭合。

## 3. 三候选裁决

### A. 逐条带积分边界层/L‑B

**生产 NO-GO。** 可继续作为二维剖面先验或局部闭合来源，但逐条带标量状态
不能表示展向输运、扭转引起的侧别迁移、曲面法向涡量或柔性变形后的涡线兼容。

### B. 全黏性涡粒子法

**生产暂不采用，验证 GO。** 它能直接解析壁面涡量生成、扩散和分离，适合
选取少量刚性/柔性代表工况，为 N2.6b/c 提供场级证据。但三维无滑移、
扩散、重映射、粒子管理与强 FSI 的成本和数值复杂度会把 FLUXV 从低阶数字
孪生变为第二套 CFD；目前 2D 变形体证据不能直接晋升为本项目 3D 生产内核。

### C. 曲面流形边界层库存 + 自由 DDE

**生产方向 GO，物理闭合仍 open。** 在真实翼面的移动二维流形上保存边界层
涡量/环量库存和必要的动量、转捩、卷吸状态；N2.6a 作为壁面输入，面内通量
表示三维输运与涡线兼容，N2.6c 只把穿过分离流形的守恒通量释放成连续 P2
DDE 面带。释放后的空间涡态统一反作用于 N1，并只经一套 Bernoulli 压力成力。

这不是把粒子法换成经验系数，而是做有层次的状态约化：

```text
移动结构几何/速度/加速度
  -> N1 外流势跳与双侧压力
  -> N2.6a 逐侧壁面界面环量源
  -> N2.6b 曲面矢量库存（面内输运/拉伸、动量、转捩、卷吸）
  -> N2.6c 三维分离流形的守恒释放
  -> N3 连续 P2 DDE 空间自由涡态
  -> N1/N2/N3 隐式回路
  -> 唯一双侧 Bernoulli/压力跳
  -> J_as^T 功共轭结构载荷
```

## 4. 为什么适合结构—运动协同设计

所有状态都保留空间位置、翼面侧别和材料身份。质量/刚柔分布改变局部位移、
速度、加速度和曲率，从 N2.6a 起逐点改变涡量生成，再通过库存、释放和 DDE
反馈改变同一面板压力。结构载荷不从总力反分配，而由压力积分通过
`Q_s = J_as^T f_panel` 直接得到；因此弯矩、扭矩和局部功天然可用于刚柔与
运动协同优化。

## 5. 预登记晋升门

1. **库存守恒门**：制造曲面单元上，壁面输入 = 库存变化 + 边界输运 +
   分离释放；内部边通量逐对抵消，不允许残差反推释放。
2. **三维兼容门**：非零二面角/扭转曲面上的矢量平行输运、法向涡量和闭合
   涡线残差网格收敛。
3. **分离释放门**：释放具有侧别、位置、方向、环量、卷吸和相对速度；由
   独立 PIV/CFD/VVPM 场验证，不用 L/T 目标拟合。
4. **空间载荷门**：压力中心、弦向/展向载荷和扭矩随网格收敛；总力只是积分
   后果。
5. **FSI 守恒门**：气动功与结构广义功逐步相等，强耦合残差达固定物理阈值。
6. **最终数据门**：刚性 V4.1 三点、118、趋势和 Fig17/18/19 通过后，再进入
   柔性翼载荷/变形/功率数据门。

## 6. 红线

- 不用总升力/推力反演库存或释放；
- 不把 LESP、BEF、`f2` 直接当持续幅值；
- 不把壁面源项直接生成一个独立 LEV 力；
- 不以全黏性粒子法的存在为由跳过 N2.6b/c 的场级验证；
- 不在 N2.6b/c 未闭合时宣称最终生产模型完成。
