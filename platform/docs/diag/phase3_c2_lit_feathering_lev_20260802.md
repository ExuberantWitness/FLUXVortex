## 2. 文献共识（可直接引用的机理句）

1. **扭转（feathering）→ 降有效攻角 → 削 LEV 强度/环量 → 涡升力降**（W1/W2/W3 一致）
2. **深扭转 → 负有效攻角 → 卸载/反号**（W4）；**深失速 → 法向力饱和（增量攻角不再加力）**（W7）
3. **涡升力与分离的关系是"伴随"而非"随攻角单调增"**：L-B 的 Cv 由分离份额（1−Kn）驱动、
   记忆衰减（W5）；|A0| 超阈直供无文献先例（N3.1.0 falsified 依据）
4. 模型当前 N3 供给（|A0| 直供 + 记忆松弛）**不满足上述任何一条**：随 |A0|（随 twist）
   单调增强、无扭转削弱、无饱和、无相位分辨
