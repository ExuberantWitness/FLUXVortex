# G0d 目标域空间证据与几何身份审计

日期：2026-07-30  
阶段：步骤①数据归因的可辨识性审计；不修改 V4.1 物理、常数或 claim 状态。

## 1. 审计问题

G0/G0c 已证明 Fig17/18/19 的周期均值总力不能唯一地区分 N1、N2 与 N3。
本轮只回答两个前置问题：

1. 是否存在 RoboEagle 同一事件、同一时钟下的双侧压力/近壁场/LEV 空间态，
   可将残差唯一挂到 N2 或 N3；
2. 当前数值几何是否具有足以支持“真实 NACA-2406 翼型”的独立来源。

## 2. Meng 2025 公开资产

裁决：`PUBLIC_DATA_NO_GO`。

- Figure 16 只给一个经过滤波的瞬时总力例，不能恢复双侧压力、壁面剪切、
  分离线、LEV 环量/质心或力矩；
- Figure 17–19 只给周期平均升力和推力；
- 正文和公开落地页没有 supplementary data、media、repository 或原始同步
  文件链接；
- 公开资料没有 wing-off/wind-on tare，因此实验总推力中翼、机构和相互作用
  的份额不可由现有曲线唯一分离；
- 若要闭合目标域空间证据，至少需作者提供同步的运动学、双侧压力或 PIV、
  六分量原始时序、滤波实现、wing-off tare 与试件几何。未经用户授权不发送
  外部联系。

公开检索到的压力、PIV、尾迹或动态失速数据集均只覆盖上述变量的一部分，
且几何、Reynolds 数、运动学或时钟不一致。它们可验证局部机理，禁止拼接成
“RoboEagle 同一事件 oracle”。

## 3. 本地高保真 oracle 可行性

裁决：`EXACT_TARGET_CFD_NO_GO`。

- 当前机器没有 OpenFOAM、SU2、NekRS 等可直接执行的壁面解析求解栈；
- 公开资料缺真实截面、三维 CAD、根部间隙、安装件、风洞边界与同步运动；
- 对该大幅三维扑翼做壁面解析 LES 的量级为数亿到约十亿单元，内存需求约
  0.5--2 TB，超出当前工作站；
- 一个代理几何上的 URANS 只能是方法 smoke test，不能被标为目标域真值，
  也不能用来选择 Fig17/18/19 的闭合常数。

## 4. NACA-2406 身份溯源

裁决：`NUMERICAL_SURROGATE_ONLY`。

- 最早可追溯来源是 2026-06-22 的用户规格“给翼面加上 2406 的 NACA
  翼型”，早于 Meng 源论文入库；
- Git 首次引入于 `0667549a8752d228fa9c82d53411811553894373`；
- `_v2_robogeom.py` 实际只使用 `m=0.02,p=0.40` 的四位数中弧线，未使用
  `t/c=0.06`，因此该零厚气动面不能区分 2406 与其他相同 24xx 中弧线；
- Meng 2025 全文没有 `NACA`、`2406`、`Eppler` 或 `E378`。其直接前代
  Cloud Owl 论文披露 E378 为设计基准，但不能证明 2025 刚性试件沿用 E378；
- 后续双侧 6% 厚壳只验证了标准 NACA 几何公式和数值运动学，不验证试件身份。

因此允许的措辞是：

> assumed NACA 24xx mean-camber reference / NACA2406-like numerical
> surrogate

禁止将其写成“实测”“精确”或“论文确认的 RoboEagle NACA-2406”。

## 5. 对 claim chain 的影响

1. N1 的 UVLM 数值算法验证与实验几何绑定必须分开。前者可保持
   `validated/frozen`；后者只能是 `partial/open`。
2. 当前 Fig17/18/19 对比是“给定数值代理几何和运动学后的条件性比较”，
   不能由总力拟合反推真实截面。
3. corrected Fig18 的推力残差近似随 \(U^2\) 增长，但在缺少 tare 的条件下，
   “实验观察边界”与“N2 分离压力”仍是竞争解释。任何候选进入实现前必须先用
   Fig15 静态滑翔锚做判别，并明确剩余不可辨识性。
4. G0d 没有取得足以从数据直接闭合 N2.6 的目标域场量，所以不得学习或拟合
   IBL 状态；下一步只能从独立一手机理预登记一个 shadow，再先通过来源论文
   自身的场/压力门。

## 6. 结果

`G0D_NO_TARGET_SPATIAL_ORACLE_GEOMETRY_CONDITIONAL`

这不是停止模型改进的理由，而是收紧证据口径：候选可继续，但必须以独立
一手文献验证机制，且对 RoboEagle 的结论保持“代理几何条件下”的限定。
