## 2. 几何与工况

- 水平拖曳水槽中的恒速前飞等效工况，弦长雷诺数 `Re = 10,000`；论文
  报告通过随水温调整拖曳速度，把 Reynolds 数控制在约 `±2.5%`。
- 矩形碳纤维平板，圆钝前缘，弦长 `c = 0.120 m`，厚度
  `t/c = 2.5%`。论文未公开精确前缘半径、截面坐标及尾缘细节。
- 水面 skim plate 同时消除自由表面影响并充当对称面。物理浸水半翼展长
  约 `2c = 0.240 m`，等效全翼展长 `b = 4c = 0.480 m`，有效
  `AR = 4`，等效参考面积 `S = bc = 0.0576 m^2`。
- 两个轴位：前缘轴 `x_p/c = 0` 和中弦轴 `x_p/c = 0.5`。
- 平板先以 `alpha = 0 deg` 恒速平移，触发后在一个弦长的平移距离内
  俯仰至 `45 deg`，随后保持该角度。
- 恒速俯仰段约化俯仰率定义为
  `k = alpha_dot*c/(2*U_inf) = 0.392`。理想的 `45 deg/1c` 运动给出
  `k = pi/8 = 0.392699...`；二者只相差论文报告精度。
- 俯仰启停采用 Wang--Eldredge 平滑 ramp，论文给出的平滑参数为
  `a_s = 11`。

代码中的 `U = 0.080 m/s` 是满足所报 `Re/k` 的相似尺度选择；论文会随水温
调整实际拖曳速度，并未冻结唯一的米制速度。无量纲载荷比较由 `Re`、`k`、
几何和运动决定，不把该尺度选择当成额外实验观测。

## 3. 数字化方法

1. 用 Poppler `pdftocairo -f 15 -l 15 -svg` 把 Figure 21 所在页面转为
   SVG，保留出版 PDF 中的矢量路径。
2. 按黑色、虚线、长路径三个条件识别恰好两条实验曲线；不从栅格截图拾点。
3. 对 SVG 的 `M/L/C` 路径逐段采样，并使用图框矢量网格给出的坐标和轴限
   映射到 `s/c` 与 `C_L`。
4. 分别把两条路径线性插值到共同网格
   `s/c = 0.00, 0.01, ..., 5.00`，共 501 行。CSV 中的 9 位小数是确定性
   导出精度，不代表实验有 9 位有效数字。

Figure 21 的实验线已经是作者的 `Experimental (Smoothed)` 数据：原始测力
以 `1 kHz` 采样，每工况重复 10 次，随后采用 100 点移动平均。当前数字化
不再施加额外滤波。

## 4. 观测契约：只有升力，没有实验阻力

论文使用二分量天平，并把法向/切向力换算到升力和阻力方向，但正文明确写明
“Only lift is reported in this paper”。因此：

- CSV 只包含两个轴位的实验 `C_L(s/c)`；
- 不存在可用于误差计算的实验 `C_D` 或阻力曲线；
- runner 可以输出 FluxV/LDVM 自身的 `C_D` 作为模型诊断，但必须标为
  `diagnostic_only`，不得计算或声称 Stevens 阻力精度；
- 不得从升力曲线、作者 ROM 分量或天平描述反演一个“实验阻力”。

## 5. 误差与限制

- 论文没有给 Figure 21 的逐点力不确定度、误差棒、原始 10 次重复数组或
  数值表。因此不能为 501 个重采样点构造统计置信区间，也不能把它们视为
  501 次独立测量。
- 论文报告的是 10 次重复平均及 100 点移动平均；相邻 `0.01c` 数字化点高度
  相关。RMSE 是曲线一致性指标，不是 501 自由度的统计检验。
- 前缘轴在 `s/c≈0` 有很窄的非环量启动尖峰。矢量路径端点、曲线平滑和统一
  插值都会对最初几个点产生较大影响。因此预登记两个窗口：主结果使用完整
  `[0, 5]`；仅作敏感性检查的窗口使用 `[0.05, 5]`。后者不是根据模型误差
  选择的，也不能替代主结果。
- 直接测力不确定度没有公开；可引用的 `±2.5%` 是 Reynolds 数控制误差，
  论文给出的约 `2.7% U_inf` 是 PIV 误差，二者都不是 Figure 21 的逐点
  `C_L` 误差条。
- 实验是真实有限翼；作者 Figure 21 ROM 是二维理论，并使用同一实验 PIV
  得到的相对涡对流速度。因此作者 ROM 不是完全独立的盲预测。
- UVLM 几何适配器只使用零弯度平均面，不能重现 `2.5%` 厚度和未公开的圆钝
  前缘半径；这一差异会影响分离起始和启动尖峰。
