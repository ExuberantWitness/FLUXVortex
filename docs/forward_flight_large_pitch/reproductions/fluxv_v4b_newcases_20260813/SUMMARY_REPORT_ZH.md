# FluxV v4b 新工况验证阶段报告

日期：2026-08-13

状态：`qualified / WARN`。本轮结果支持“部分升力机制可迁移”，不支持
“所有新工况、升力和阻力均稳健提高”。

## 1. Razak–Dimitriadis 2014 / Lambert 2017

### 重建范围

重建了 NACA 6409 矩形刚性单翼：弦长 0.160 m，气动翼展 0.400 m，
铰轴至翼根偏置 0.150 m，根部扑幅 +/-30 deg。六个实验工况来自公开
Lambert PDF 的 Figures 9、10、11、13、14、15，涵盖 pitch-leading 和
pitch-lagging、`U=6--14.8 m/s`、`f=0.79--1.50 Hz`、不同平均俯仰角。
NACA 6409 厚度比为 9%，低于本轮排除的 10%阈值；但是 UVLM 仍只解析
中弧面，不能声称已解析9%厚度的黏性影响。

实验相位曲线直接从 PDF 矢量路径及 740 个误差棒中心提取；评分使用论文
显示的周期相位，不做相移、幅值缩放或载荷拟合。论文未公开实际64点
运动历史和俯仰轴数值位置，因此使用极值匹配正弦和四分之一弦俯仰轴，
所有结果只能称为 `nominal-motion diagnostic`。

### Full 配置结果

配置为 4×12 UVLM 面元、128步/周期、3周期、保留2周期尾迹；v4b 内部
LDVM 用512步/周期和256步尾迹窗口。

| 指标（六工况等权宏平均） | FluxV old | FluxV v4b | 变化 |
|---|---:|---:|---:|
| CL RMSE | 0.24689 | 0.23262 | 改善 5.78% |
| CL MAE | 0.20604 | 0.19265 | 改善 6.50% |
| CD RMSE | 0.05474 | 0.05349 | 改善 2.28% |
| CD MAE | 0.04417 | 0.04604 | **恶化 4.23%** |

逐工况结论并不一致：

- Figure 9、11：v4b不触发，严格退化为old；
- Figure 10：CD改善，CL轻微恶化；
- Figure 13：CL和CD均恶化；
- Figure 14：CD RMSE从0.1352降至0.0748，但CL RMSE轻微恶化；
- Figure 15：CL RMSE从0.4151降至0.2880，但CD RMSE从0.0881恶化到
  0.1436。

这说明当前 LDVM separated-minus-attached 增量在高载荷升力分支有价值，
但轴向吸力、分离阻力和三维投影账本仍不可靠。Figure 13/14/15中的局部
锯齿也表明独立二维条带并不是最终的三维材料LEV解。

Smoke→full 同时改变面元、时间步、周期数和尾迹长度，不是单因素收敛；
若干逐图RMSE变化超过20%。因此上述数字是当前full离散化下的开发结果，
不是网格收敛或泛化认证。

## 2. Meng 2025

### 几何与定义审计

实现采用 Figure 11 的半展长800 mm、根弦287 mm、内段340 mm，外段轮廓
按图重建，主梁位置按图估算为约0.27根弦。论文未给翼型/厚度，所以使用
零弯度数值薄膜中面，没有引入NACA0012/0013。论文所谓 `twist` 对刚性翼
是整翼绕主梁旋转；没有公开展向扭转律，代码没有凭空施加线性展向扭转。

Figure 16 工况为 `U=8 m/s, alpha=5 deg, f=2 Hz`，扑动幅值45 deg和
扭转幅值0/22.5/45 deg均按峰峰值解释。Equation (11) 中重力先在传感器
坐标加入、再旋转；展开后重力只给升力增加 `G`，不给净推力增加常数。

论文未报告 wind-off 惯性扣除、空支架/机构风阻tare、空气密度、采样率、
重复次数或实验误差条。因此 `net thrust` 是整套平衡仪系统量，不是定义
严格一致的纯翼气动推力；这会主要污染流向载荷比较。

### 三个扭转幅值的 smoke 诊断

| 峰峰扭转 | 实验L / Tnet (gf) | FluxV old L / T (gf) | old+frozen-polar L / T (gf) |
|---:|---:|---:|---:|
| 0 deg | 824 / -139 | 664 / +105 | 639 / +55 |
| 22.5 deg | 794 / -80 | 647 / -4 | 645 / -7 |
| 45 deg | 620 / -230 | 617 / -237 | 591 / -260 |

模型能够复现实验中“扭转增大后升力和净推力大幅下降”的总体趋势，并在
45 deg点非常接近；但0和22.5 deg升力明显偏低，0和22.5 deg流向载荷
存在整机tare量级的差异。因为观测定义不一致，这里不计算或宣称绝对推力
精度。

完整v4b不能合法报告：Meng没有截面、静态极线或LESP阈值。强制移植
Yang薄板 `Lcrit=sin(5 deg)` 后，8条带的48/96/128步测试全部出现奇异
矩阵；此前6条带测试产生符号改变、数量级爆炸的有限值。该分支被明确
拒绝，没有使用clip、从实验反推阈值或补阻力偏置。这是当前模型跨截面
泛化失败的证据，不是孟等实验造假或定义错误的证据。

## 3. Yang 2023 与 Baik 2012

- **Yang 2023**：130×250 mm、1 mm巴沙木矩形刚翼和名义四连杆运动可
  高保真重建；`U=5.5 m/s, f=2.5 Hz, AoA=0--25 deg`很明确。但只公开
  六个周期平均升力/推力点，没有激光测得运动历史、相位载荷和完整tare。
  适合作为三维均值次级验证，不适合相位精度验证。2023与2025机构不同，
  不可混用。
- **Baik 2012 JFM**：使用厚度比2.3%或6.25%的圆边平板，不触发本轮厚翼
  排除。W1--W4几何、四分之一弦俯仰、非简谐沉浮、完整相位
  `Cl/Cd/Cm/Cp`、2000 Hz采样及载荷tare更完整，是下一步优先的二维
  LEV验证集。必须使用博士论文补回静态水动力后的 corrected total loads，
  不能混用AIAA前驱的相对载荷。

## 4. 本轮排除

- 新的 NACA0012/NACA0013 工况：按要求排除；
- Thielicke 2011 MAV：按要求排除；
- Heathcote 2008柔性翼：暂缓；
- Figure 12 Razak拖曳：各曲线被单独减去自身最大值，排除绝对CD评分。

## 5. 下一步模型优先级

1. 修复 LDVM 条带的数值条件和时间步/核半径耦合，完成步长、wake cap、
   UVLM网格三个单因素敏感性；
2. 不再把二维轴向吸力增量直接加到有限翼CD，改为守恒的三维LEV/尾迹
   反馈或有明确唯一所有者的流向力账本；
3. 用Baik W1--W4冻结相位升力/阻力验证，先于任何参数调节；
4. Meng只有在获得截面/静态极线或构建有界、截面无关的脱涡判据后，才
   重新启用完整v4b；不得用Figure 16--19载荷挑选LESP阈值。
