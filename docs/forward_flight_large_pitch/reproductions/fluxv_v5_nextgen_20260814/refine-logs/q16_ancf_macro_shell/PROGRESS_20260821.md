## 1. 本轮已经实现

### 1.1 固定 Q16 数学状态

- 唯一新单元为 4×4 Gauss--Lobatto Q16；没有 Q9。
- 每节点 `r(3)+g(3)`，每单元 16×6=96 DOF。
- 已实现三次张量积形函数、导数、三维退化壳映射、协变基、完整
  Green--Lagrange 六分量和一致参考质量。
- Kronecker、partition of unity、三次场、有限刚体运动、厚度伸缩、质量门通过。

### 1.2 Q16 三维连续体 CUDA 核

- 固定 6×6×3 积分。
- 总拉格朗日 StVK 基线：`F/E/S/P`、内力、一致质量作用、解析 `Jv`。
- CUDA float64 矩阵自由实现；按 batch×element×quadrature 和
  batch×element×node×coordinate 并行，不装配 96×96 刚度块。
- CUDA 对独立 NumPy oracle 的 relative L2：force `1.94e-15`、Jv
  `3.29e-16`、mass `1.91e-16`。
- 这仍是未加 ANS/EAS 的连续体基线，不能据此宣称薄壳无锁死。

### 1.3 功共轭 CUDA 气动—结构传递

- 任意 `(xi,eta,zeta)` 气动点由 Q16 位置/导演共同插值。
- 气动力用精确转置映射回 96 DOF；`zeta!=0` 时保留导演力和厚度力臂。
- 虚功、总力、总矩门通过；旧“四角点均分”作为负控失败。
- CUDA 转置使用固定序 CSR gather，不用浮点 atomic scatter；注册重复运行位级一致。

### 1.4 LEV/TEV/free-wake 事务底座

- 状态显式同时包含 bound、separated LEV、newborn TEV、free-wake geometry/gamma。
- predictor trial 读取同一 pre-step snapshot；重复 trial 不推进 live owner。
- 只允许最新、精确 issued proposal 提交一次；abort 不修改父态。
- hostile trial 先修改再抛错时能恢复父态；clean retry 与 fresh run 一致。
- 当前是独立控制面 oracle，尚未绑定真实 `CudaJointLEVTEVSolver`。

### 1.5 shared-node Q16 网格

- 2×1 Q16 网格由断开的 32 节点降为 28 个唯一全局节点，共享边严格共用 4 个三次节点；2×2 网格为 49 个唯一节点。
- CPU 完成全局到局部 gather、局部到全局装配及 energy/force/mass/Jv；CUDA 采用按全局节点的固定 occurrence-CSR gather，不用浮点 atomic scatter。
- shared-node focused 10/10，兼容连续体与 MITC16+ANS/EAS 两条路径均已接入；CUDA 对独立 mesh oracle 与重复位级确定性门通过。

### 1.6 MITC16 协变应变投影

- 依据 Bucalem--Bathe MITC16 冻结 3×4、4×3、3×3 tying 空间；没有 Q9、降阶积分或按厚度切换公式。
- tying-point、刚体运动与 exact component-order 门通过。
- 制造圆柱 Kirchhoff 弯曲中，寄生横向剪切 L2 从 `2.2154e-4` 降至 `2.2949e-6`，抑制 `96.54×`。
- 投影器自身仍把 `E33` 标为 `compatible-not-ans-eas`，职责边界不变；完整结构算子在下一层通过 Q16 nodal ANS 与 thickness-linear EAS 处理 `E33`。

### 1.7 厚度 ANS+EAS 与局部凝聚

- Q16 节点采样的 `E33` ANS 与一个厚度线性 EAS 内部参数已实现；EAS 使用中心映射和局部/中心 Jacobian 行列式比，保持畸变参考几何下的常应力正交性。
- EAS 参数逐单元解析求解并从能量、内力和解析 Jv 中局部凝聚；当前构形奇异或反向时 fail closed。
- 圆柱诊断中能量从 `6.9807475007375555` 降到 `5.698696956935329`；stationarity relative residual 为 `6.05e-14`。
- 四个冻结厚度比 `1e-3, 1e-2, 5e-2, 1e-1` 均保持有限；这只是有限性/一致性门，不等价于锁死收敛证明。

### 1.8 ANS+EAS CUDA 与共享网格

- tying sampling、projected strain/B、EAS 标量凝聚以及按自由度确定性 gather 均在 CUDA 上执行；不组装 96×96 刚度矩阵、不用浮点 atomic scatter、无 CPU 数值回退。
- 单元 CUDA 对 NumPy oracle：alpha 最大绝对误差 `2.46e-21`，force/Jv relative L2 为 `6.24e-12` / `9.17e-16`。
- 投影共享网格 CUDA 对 CPU mesh oracle：force/Jv/mass relative L2 为 `4.25e-15` / `8.76e-16` / `1.84e-16`，重复 force 位级一致。

### 1.9 Q16 边界约束 owner

- 夹持根部由唯一全局 owner 冻结，不在单元内重复约束；2×1 网格根部为 7 个唯一节点、42 个 position/director DOF。
- state enforcement、free projection 与 reaction extraction 满足精确互补分解；输出只读。
- CUDA 使用相同 mask 和 prescribed state，拒绝 host、float32、错形状与非有限输入；不使用 CPU 数值回退。

### 1.10 CUDA Newmark--Newton--CG 结构试步

- 固定平均加速度 Newmark `beta=1/4, gamma=1/2`；非线性 residual 为 `M a + f_int - f_ext`，Newton action 为 `M/(beta dt^2)+K_t`。
- mass、ANS/EAS internal force、analytic Jv、vector update 与批量 CG 全部驻留 CUDA；host 只读取有界收敛/失败标量并选择 active batch。
- batch-2 小载荷以 1 次 Newton、32 次 CG 收敛到 `3.00e-11`；夹持 state/velocity/acceleration exact。
- 强制 max-iter 失败时输入位级不变，clean retry 与 fresh solve 位级相同；极小/极大 `dt`、host、float32、非有限及 boundary drift 全拒绝。
- 暖机诊断 batch 1→32 的每样本时间约 `49.4→5.06 ms`；这是并行性诊断，不是正式规模 speedup 声明。

## 3. 对用户两个问题的当前回答

1. **前缘涡、尾缘涡和自由尾迹是否已经进入 predictor--corrector？**  
   事务状态和试算/提交语义已经完整覆盖 LEV、TEV 和自由尾迹；但真实
   `CudaJointLEVTEVSolver` 尚未接到该事务。因此“接口和失败语义已实现”，
   “真实气动 owner 的联合时间步已实现”仍为否。

2. **是否具备 Q16 + LEV/TEV/free wake + predictor--corrector + FSI 条件？**  
   Q16 运动学、连续体 residual/mass/Jv、CUDA 功共轭传递和事务原语均已具备；
   非线性结构试步已经建立；还缺结构基准/长时稳健性、真实气动 adapter 和完整
   coupled rollback/commit ledger。因此已经从“只有零件”推进到“主要数值核齐备”，
   但还不能运行可信的完整柔性翼 FSI。
