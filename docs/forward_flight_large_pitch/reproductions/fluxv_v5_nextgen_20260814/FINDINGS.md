# Research Findings

## v5a failure

The equilibrium-residual plus high-passed integrated LDVM discrepancy is not a
universal ownership repair. It helps Yang means but strongly worsens Scherer
Figure 14 and all Baik filtered channels. Do not tune `lambda_tau` against those
target curves or rerun the same cache proxy as if it were canonical.

## v5b boundary reached

The shared material TE/LE state and single surface-pressure ledger are reusable
implementation components. The standalone architecture, however, changes the
TE wake, time layer and force owner even with LEV disabled. Future work must move
the shared wake into the native Ptera solver so the no-LEV branch is exactly the
current FluxV path before any paper accuracy evaluation.

## Routing

Outcome: negative for the intended three-paper improvement claim. Continue only
with a native-solver G1 repair; then implement G6 and re-enter paper scoring.

## v5c feasibility routing

A second result-to-claim review of the complete 22-condition matrix gives a
`partial` feasibility verdict and routes to a **pivot within FluxV**. Continue
only with a conservative v5c that is exactly the corrected v4b when disabled,
uses strip-local mutually exclusive ownership, and initially changes only a
bounded causal axial-suction-loss ledger. Do not revive the v5a global
equilibrium residual or the standalone v5b TE/load replacement.

The three current papers are now development/confirmation sets because their
full outputs have been inspected repeatedly. Any future claim of case-agnostic
generalization requires a separately frozen unseen transfer case.
