# Mancini 2017 有限翼快速机动：FluxV v4b 直接测试报告

## 1. 结论先行

本次直接迁移**运行成功**，冻结 v4b 在快、慢两个有限翼俯仰工况中均降低了
相对未增强有限翼 UVLM 的整翼升力曲线 RMSE：

- 快俯仰：`1.40043 -> 1.21842`，降低 `13.00%`；
- 慢俯仰：`0.37777 -> 0.29080`，降低 `23.02%`。

因此，零拟合的 v4b 修正在这篇新文献上显示出**可迁移改善信号**。但这不是
“已经较好复现实验”的结论：快速俯仰初期计算峰值约 `7.04`，实验峰值约
`4.83`，时间也从实验的 `t*=0.96` 提前到 `t*=0.03`；快速工况的 v4b RMSE
仍为 `1.22`。更诚实的判定是：

> v4b 对两个工况的积分误差和正偏差都有改善，慢俯仰效果较明显；快速俯仰
> 的初始峰值、相位和后续振荡仍有重大模型差异，当前只能称“诊断性迁移
> PASS”，不能称“论文定量验证 PASS”。

## 2. 被复现的实验工况

文献为 Peter Mancini 2017 年博士论文 *Experimental Investigation into
Unsteady Force Transients on Rapidly Maneuvering Wings*。本次只采用其中真正的
有限翼俯仰工况；用户列出的近二维翼型/厚翼文献均未进入本次测试。

| 条目 | 冻结值 |
|---|---|
| 翼型与平面形 | 矩形有限翼平板，前后缘圆钝 |
| 弦向长度 | `c=76.2 mm` |
| 展向长度 | `b=304.8 mm` |
| 展弦比 | `AR=4` |
| 厚度 | `t/c=5%` |
| 来流 | `U_inf=0.26 m/s` |
| 雷诺数 | `Re=20,000` |
| 俯仰轴 | 前缘，`x_p/c=0` |
| 运动 | `0 deg -> 45 deg` 后保持 |
| 快俯仰 | `s_a/c=1`，`k=0.39`，Eldredge `a=15` |
| 慢俯仰 | `s_a/c=6`，`k=0.065`，Eldredge `a=4` |
| 评分窗口 | `0 <= t*=tU_inf/c <= 5` |
| 实验观测 | Figure 4.13(b) 的整翼总升力系数 `C_L(t*)` |

这里的 `x/c` 是**弦向**坐标，`y/b` 是**展向**坐标。论文在约四分之三
展向位置给出 PIV/染料观察，并明确讨论三维展向流动；但 Figure 4.13(b) 没有
沿展向的截面载荷数据，所以本次不能声称验证了展向载荷分布。

## 4. “直接使用 v4b”的准确含义

Baik 专用脚本 `platform/warp_vpm/bing_v4b_refined.py` 会读取 Baik 工况数据，
不能原封不动拿来跑 Mancini，否则会混入错误几何和旧观测。这里采用的“直接”
是算法级零拟合迁移：

1. 冻结原 v4b 基线 SHA-256：
   `80d6bb5b18f356516439670e01d5f09a88662cb96911b317de5ba6982782c271`；
2. 复用现有 `ldvm_uvlm_correction.py` 的成对 LDVM “分离减附着”增量和有限翼
   投影；
3. 保持 `Lcrit=0.11`、增益、相位和 LDVM 结构不变；任何阈值改动均被测试
   拒绝；
4. 只新增 Mancini 的有限翼几何、Eldredge 运动和数据适配；
5. 所有预测先完成，最后才加载实验 CSV 评分。把实验 CSV 路径改成不存在的
   文件，v4b 预测逐点不变。

基础载荷来自 Ptera 有限翼 UVLM，计算半翼使用中面对称，两个物理翼尖仍为
自由翼尖。平均面用零弯度 NACA0012 适配器表达平板；这不能解析实验的 5% 厚度
和圆钝前后缘，是现阶段的重要模型误差来源。

## 5. 正式网格与结果

正式设置为弦向 4 面元、半翼展向 12 面元（完整翼 96 面元），UVLM 每弦长
64 步、共 449 个时刻、最大尾迹 384 行；v4b LDVM 每弦长 96 步。两工况使用
相同设置且没有调参。

| 工况 | 模型 | RMSE | MAE | 偏差 | 相关系数 | 预测峰值 `C_L@t*` |
|---|---|---:|---:|---:|---:|---:|
| 快俯仰 | 未增强 UVLM | 1.40043 | 1.15652 | +1.00902 | 0.57576 | `7.0426@0.03` |
| 快俯仰 | 冻结 v4b | 1.21842 | 0.77569 | +0.50180 | 0.61025 | `7.0426@0.03` |
| 慢俯仰 | 未增强 UVLM | 0.37777 | 0.36343 | +0.36343 | 0.99037 | `2.7596@5.00` |
| 慢俯仰 | 冻结 v4b | 0.29080 | 0.24535 | +0.23982 | 0.96800 | `2.2055@4.46` |

实验峰值分别为快俯仰 `4.8289@0.96`、慢俯仰 `2.0482@4.97`。慢工况中 v4b
明显减小了幅值正偏差，但局部 LDVM 波动使相关系数从 0.990 降到 0.968；因此
不能只看 RMSE。快工况的最早强峰几乎仍由 UVLM 主导，说明当前二维分离增量
不能修复有限翼初始附加质量/三维 LEV 建立的全部误差。

正式双工况运行耗时 `2043.82 s`（约 34.1 分钟），比计划估算上限 30 分钟
多约 4.1 分钟。运行没有降阶或重启。JIT smoke 与禁用 JIT smoke 的逐点预测
最大差约 `6.93e-14`，v4b 增量逐点完全一致，因此正式运行启用 JIT 不改变
科学路径。

## 7. 当前差距与下一步

本次已经完成“新文献工况闭合、图线数字化、零拟合 v4b 直接测试、中文证据图、
独立指标重放”。还不能越过的边界是：

1. 只有整翼 `C_L`，没有实验展向载荷分布；
2. UVLM 平均面未解析 5% 厚度和圆钝边；
3. v4b 的 LDVM 增量仍是二维截面修正，不是与有限翼共同演化的三维 LEV；
4. 当前只有 smoke/full 两档，不能证明网格独立或渐近收敛；
5. 图线数字化误差和作者测力不确定度尚不能合成严格的逐点统计区间。

若继续，应先预注册三档空间/时间收敛矩阵，并把快工况的“初始峰值幅值与相位”
列为单独失败指标；在取得可靠的展向 PIV/载荷数据前，不应把本结果升级为三维
展向载荷验证。
